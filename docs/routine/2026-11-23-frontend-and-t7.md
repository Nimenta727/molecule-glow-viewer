# 2026-11-23 · 前端展示能力提升与完整的 T7 噬菌体

## 用户要求
1. 选了哪个选项要显示为选中。
2. 蛋白质资源（所有模板）必须能展示卡通、主链、团块、价键，要有细节；要能看出氢键和各种相互作用力，“画在残基上没用”。
3. 光影包不是换背景和光泽：要像论文描边白底那样有质感、残基与背景柔和过渡；每种展示方式都要在多个光影包里调过；白底描边要重做。
4. 噬菌体模型太草率：要一个完整的整体，能拆解；发布时不设限，直接发布。随后：T7 补全后发布，再做 T4。

## 做了什么
- **选中状态**：`apps/viewer-web/view-panel.mjs` 的按钮组（显示方式、颜色、表面、作用力、光影、鼠标模式、只看某链）按下后保持高亮（`aria-pressed`）。
- **三维卡通**（`plugins/structure/cartoon-mesh.mjs`）：Catmull–Rom 曲线 + 截面扫掠；螺旋宽带、折叠带箭头、卷曲/主链圆管、核酸圆管；顶点法线随三角形给出（平滑着色）；几何存在可增长的 Float32Array 里；三档细度（普通 / 大复合体 / 整颗病毒用粗圆管）。场景包里的预览仍存轻量的旧几何（`detail: 'preview'`），否则大模板会超出容量。
- **价键**：每根键是有明暗的实例化圆柱（viewport 新增 `cylinders` 图层）；上限从 300 个残基提到 3 万（球棍 6000）。
- **相互作用**：`glow.hbonds({part, kinds})`（氢键/盐桥/疏水），画成虚线圆管（`dashedTubes`，参与深度测试），两端残基自动设为价键；`interactionsBetween` 支持同一部分内部（`within`）。
- **光影包**：glow 渲染新增墨线描边（深度跳变）、分子到背景的光晕、体积明暗；四个包重新调参，对照图覆盖 5 种显示方式 × 5 种光影。
- **大结构的稳定性**：拆装（`pieces.mjs`）、镜头对准、B 因子着色里对几十万个点的数组展开改成循环。
- **T7 完整模型**（`tools/build-phage-model.py`）：衣壳按衣壳粒分链（60 个六聚体 X01–X60、11 个五聚体 P01–P11，按 3J7X 的不对称单元：6 条链成一个六聚体环）；6 根尾丝补全：N 端（9JYZ，3–143）、中段 144–370（**没有任何实验或预测结构**：AlphaFold DB 不收录病毒蛋白，ESMFold 公开接口超时，按长度和折角画成三股 Cα 示意链）、末端 371–553（4A0T 晶体结构）；尾丝先从尾部向外再折回、全部在衣壳外（脚本核对：衣壳半径内的尾丝原子 0 个）。输出 `t7-virion-parts.json`（部件名 → 链）。
- **T7 作品**（`tools/make-phage-works.cjs` 的 `t7-virion`）：三维卡通、按部件着色（示意中段浅粉）、论文白底描边、侧视；讲解分开写实验结构与示意部分并列出来源。约 120 MB；Viewer 打开约 45 秒（软件渲染），拆装 203 块。
- **发布**：作品由新的 `works-release` 工作流在 GitHub 上从公开 PDB 条目重新生成并附到发行页（文件超过仓库单文件上限）；删除一次性的 `release-cleanup` 工作流。
- **检查**：`tools/template-modes-check.cjs` 逐个打开官方模板并试四种显示方式；`tools/viewer-view-panel-check.cjs` 检查按钮和选中状态。

## 没做到 / 要注意
- 没有真实显卡和真实 Windows 的验收；整颗病毒在真实显卡上的帧率未知。
- T7 作品接近 128 MB 的场景包上限；T4（几百万个原子）需要先放宽格式上限。
- 尾丝中段、各部分相对位置、DNA 缠绕都是示意。
