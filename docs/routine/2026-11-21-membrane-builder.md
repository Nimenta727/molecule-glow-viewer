# 2026-11-21 · B3 膜的构建与渲染

## 做了什么

- `plugins/structure/membrane-builder.mjs`（纯几何，单位 Å）：四种膜形状——`plane`（宽、高，法线 +z）、`sphere`（囊泡）、`capsule`（杆状：圆柱加两个半球，细菌包膜的形状）、`ellipsoid`；每个形状有参数化的中间面（点与外向法线，按面积均匀）和面积（球、胶囊是精确公式，椭球用 Thomsen 近似，误差 1.1% 以内）。`buildMembrane` 生成外、内两个小叶面（中间面沿法线各移 `thickness/2`）的三角网；`sampleSurface`——在膜面上按面积均匀、带种子地取点，可要求最小间距（拒绝法，会说明实际放了几个，供插膜 C2 与组成规划 C3 使用）；`rotationFromZ`、`placePoints`（把 +z 转到指定法线、平移、缩放到视口单位）。
- Viewer：命令 `glow.membrane({ shape, thickness?, normal?, offset?, opacity?, resolution? })` / `"clear"`，画成两个半透明小叶面（外层暖色、内层冷色），在结构的坐标系里；参数逐项校验。
- 复用 `setOverlayMesh`，没有另写渲染。

## 验证

- 单测 +6 项：面积与教科书公式一致；外/内小叶面分别在半径 ±20 Å；法线为单位向量且朝外（平面朝上）；胶囊每点离轴线段恰好 `radius`；取样的种子化、按面积均匀（上下半球点数接近）、最小间距、太挤时少放并如实报告；旋转把 +z 送到任意法线且为真旋转。
- 真实浏览器 `node tools/membrane-check.cjs`：在 KcsA（1K4C）周围画平面（场景三角形增加 2 × 4608）与囊泡；写错的形状、负半径被拒绝并说明；默认厚度会提醒“未核对来源”，自己给的厚度不提醒；清除后三角形数回到原值。截图 `docs/images/membrane-vesicle.png`。

## 如实说明

- **厚度默认 40 Å 是我给的整数，没有核对来源**，命令回包里会提醒；真实膜的厚度因组成与测量方法而异；
- 只是两个光滑的曲面，**没有画出脂质分子、没有疏水核心与头部的区别、没有嵴或不规则形状**；
- 与结构的相对位置要作者自己给（`normal` 与 `offset`）；和“自动定膜”（根据跨膜段找膜平面）还没有联通，这是 C2（膜蛋白插膜）要做的；
- 一次一个膜；双层膜（革兰氏阴性菌的内外膜）要用两次调用，还没有一次给出。
