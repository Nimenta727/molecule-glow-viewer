# 2026-11-20 — 前端细节：机理镜头、粒子标签、重复步骤列表

## 做了什么
- **机理镜头过近**：原因是点“查看机理”时镜头只对准当前步骤的**第一个**参与对象（ATP 第 1 步只有 a 亚基这一条链），而步骤跳转时对准的是全部参与对象。改为两处都对准全部参与对象，并新增 `minRadiusFraction`：镜头不会比整体半径的一半更紧（`MECHANISM_CONTEXT = 0.5`），保证膜和上下文可见。ATP 机理视图镜头距离 7.3 → 11.7（系统视图 21.4）。
- **粒子标签白框**：标签画布原来用不透明白底，并且 Sprite 写入了深度缓冲，墨线后处理把方块边缘也描成了框。改为带纸色描边的字（halo），并且 `depthWrite: false`。
- **重复的步骤列表**：机理模式下面板里有两份步骤列表（模式面板一份，播放器控件一份），因为隐藏逻辑只在播放刷新时才执行。移到 `syncMode`（模式变化时）执行，机理模式下只留模式面板那份。

## 验证
- 浏览器（软件渲染 Chromium）：ATP 官方包进入机理视图，量得镜头距离、截图 `docs/images/viewer-mechanism-camera-1440.png`（标签无框，膜圆盘入画，仅一份步骤列表）；211 项测试当时全部通过。
- 未在真实 GPU/EXE 验证。镜头与标签属于渲染层，没有 Node 单元测试，靠浏览器截图把关。

## 需要你知道的
- 第 1 步（质子动力势）只涉及 a 亚基，镜头聚焦膜区域，F1 头部会被裁掉一部分，这是“聚焦参与对象”的结果；想让整体始终可见，可以把 `MECHANISM_CONTEXT` 调到 0.8–1。
