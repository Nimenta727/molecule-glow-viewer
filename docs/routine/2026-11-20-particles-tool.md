# 2026-11-20 — 4.4.2d 粒子作为制作工具（4.4.2 收尾）

## 做了什么
- **新插件 `org.glow.motion`**（`plugins/motion/index.mjs`）注册第一个工具 `org.glow.tool.solution-particles`（“溶液粒子与流”）。工具协议新增 **`runtime: 'layer-v1'`**：画在结构上的一层，没有自己的播放时钟（原来只有 `player-v1`）。`audience` 同时是 view 和 author。插件跟随结构插件启用（`mechanism-catalog.mjs` 新增 `toolPlugins`），三个机制播放器的工具列表不变。
- **配置与校验**（`solution-tool.mjs`）：`{seed, scale, pools[], flows[]}` 存在 `scene.tools[].config`。工具自己的校验器：个数/流速夹在范围内，保留写了一半的流（先选分子、再填起点终点），选“移除”的项消失，幂等。作者字段由 `solutionAuthorFields` 动态给出（每个池和流各一组 + 一个空位，选了分子种类就自动补默认个数），所以 **Studio 的工具页没有为它写任何专门代码**。
- **Viewer**：“溶液粒子”面板成为这个工具的运行端：保存时写入/更新 `scene.tools[]` 的条目（没动过粒子面板的作品不被改动），打开时读这个条目（旧文件里的 `viewerState.particles` 仍可读）。motion 插件被停用时面板隐藏、粒子清除、配置原样保留；重新启用后回来。
- **粒子名字卡片**：鼠标悬停（触摸/笔：点按）一个粒子，显示“名字 · 溶液中的分子/粒子流”。视口新增 `pickParticle`：被蛋白挡住的池粒子点不到，流（画在蛋白之上）点得到；名字只用文本显示。

## 怎么验证的
- 单元测试 5 项（插件注册与停用释放、配置校验与幂等、按 Studio 的方式经通用工具模型编辑：空位新增/改种类/改个数/移除、被拒绝的编辑不改配置、自定义物种可编辑与上限、无需绑定角色）；全套 319 项通过；`check-feature-parity`、`check-copies` 通过。
- **浏览器实测**（预装 Chromium，软件渲染，Viewer 与 Studio 均无页面错误）：
  - Studio：导入 1K4C → 工具页下拉里有“溶液粒子与流” → 添加后出现种子/时间尺度/第一个池/空位等字段 → 在空位选 K⁺ 得到默认 20 个、改成 35 → 加一条流（H⁺，chain A → chain C）→ 时间尺度改“快” → 导出；导出的场景文件里 `scene.tools[]` 有这个条目且配置完全一致。
  - Viewer：打开这个导出，启用结构插件后面板列出 H⁺×20、K⁺×35 和那条流，时间尺度为“快”；取消结构插件后粒子面板隐藏。
  - Viewer 自己的保存→关闭→重开：条目写在 `scene.tools[]`，重开后列表/时间尺度/说明恢复，**视口逐像素相同**；“全部移除”后回到无粒子原图。
  - 悬停：移到一个 K⁺ 上显示“K⁺ · 溶液中的分子”，移开后消失（`docs/images/particles-hover.png`）。
  - （测试里有一次 Studio 的“终点”被丢掉，原因是我的脚本没让输入框失焦、change 事件被下一步的重绘冲掉；补了 Tab 提交后保存的配置完整。）

## 需要你知道的
- **Studio 里还没有粒子预览**：能编辑配置、导出，要到 Viewer 里才看到粒子。
- **事件标签没有画**：这一层本身没有“事件”（没有反应），事件日志和标签要等 4.4.3 的反应事件才有内容；`EventLog` 已准备好。
- Studio 的分子种类下拉只有标准物种；用 Viewer 打开的作品里如果有自定义物种名，会原样保留并可继续编辑。
- 没在真实 GPU/桌面版上验证；实测是软件渲染。
