# 2026-11-21 · 0.7.0 发布准备

## 做了什么

1. **颜色随存档保存**：`glow.color` 的结果（方案与单链颜色）写进保存包里结构资产的 `viewerState.colors`，重开时校验后恢复（损坏的块被忽略）；`glow.info()` 新增 `colors`。真实浏览器里验证：载入 6ZPO，按链上色并把一条链染红，导出，恢复默认，再载入导出的包 → 颜色回来。
2. **细胞一角布局用到 Viewer**：打开细胞一角包时，通道按经典规则摆在核糖体切面里、膜位置下方（`apps/viewer-web/legacy-layout.mjs` 调用已与经典核对的 `corner-layout.mjs`；平面取场景默认视角，因为这个布局里没有残基名，无法求精确的 E→A 方向）。真实浏览器截图：`docs/images/cell-corner-layout.png`。
3. **版本 0.7.0**：`desktop/package.json`、锁文件、各处版本说明、`docs/releases/desktop-v0.7.0.md`；数值对照基线因锁文件哈希变化重新生成（数值不变）。

- 整细胞区域层级自己的粗略内容；官方作品里 7CGO/8YJT/6YKM/1UCU/4V6F 等结构登记为资源（要结构哈希评审）；回退/干预界面的肉眼确认；真实 GPU。
