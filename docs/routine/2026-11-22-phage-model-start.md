# 2026-11-22 噬菌体静态模型：平台准备与首次渲染

## 做了什么
- 新增 `tools/build-phage-model.py`：把 T7 噬菌体的几个实验结构（头 3J7W、尾-门户复合体 9JYZ、核心 9JYY）拼成一个文件 `t7-virion-model.cif`（约 43.7 万原子，不进仓库，由脚本生成）；DNA 为 39,937 bp 的示意性螺旋轨迹。
