# 2026-11-21 · 第一层：蛋白质模板（导入、科研信息、模板库）

## 为什么做

你把平台理解为三层：**基础**（程序本体 + 蛋白质模板 + 插件）→ **作品**（在 Studio 里用模板加插件制作）→ **展示**（Viewer）。蛋白质模板是第一层：**完全静态、原样的原文件**，附带来源、授权和科研基础信息；它不含任何动画或拆分。此前这一层只有官方登记的 29 个资源（只读），用户没法导入自己的文件，文件里的科研信息也没有读出来。

## 做了什么

1. **科研基础信息读取**（`plugins/templates/structure-card.mjs`）：只读 mmCIF 头部（遇到坐标行就停，38 MB 的条目也只要几毫秒）或 PDB 格式的头部记录，得到：标题、关键词、实验方法、分辨率、物种、每个实体（名称、类型、份数、链、长度、序列、来源物种、突变）、配体与离子的种类和个数、生物组装体个数、文献（标题、年份、DOI）、存档与发布日期。文件没写的一律留空，不猜。
2. **模板库**（`plugins/templates/library.mjs`，存储可注入，应用里用 IndexedDB）：
   - 导入自己的文件：**授权必选**（CC0 / CC BY / CC BY-SA / 仅自己 / 不清楚），CC BY 要署名；“不清楚”按“仅自己使用”，`embedAllowed=false`，不会进入任何发布的包；
   - 从 PDB 编号添加（生成与工坊资源区相同的记录：`res.rcsb.<编号>`，CC0，记录哈希）；
   - 同样的字节是同一个模板；取回字节时核对哈希，损坏的副本拒绝打开；记录（来源、授权、哈希）导入后不可改，只能改名称和备注；存储失败（磁盘满、无痕窗口）给出原因而不是半途保存。
3. **模板包 `.glowtpl`**（`plugins/templates/package.mjs`）：原文件加记录的 zip，可交给别人或备份；读取严格（大小限制、路径限制、文件与哈希必须一致）。包里声明的来源与授权只是发包人的说法：重新导入时一律当作本机文件，“来自 PDB”只作为“自称来源（未核对）”保留。
4. **界面**：工坊对话框新增“我的模板”分页（`plugins/templates/zone.mjs`）：添加表单、卡片（方法、分辨率、物种、组成、配体、突变、文献链接、授权、文件哈希、备注）、搜索、改名/改备注、导出模板包、删除（要点两次确认）；Viewer 里“打开结构”，Studio 里“用此模板新建作品”。
5. **改名**：原来的“模板区”（其实是做好的静态作品）改叫“静态作品”，把“模板”这个词留给第一层。

## 验证

- 单测：读取器对真实条目头部（4AKE、1K4C，来自 RCSB，CC0）的断言——分辨率、物种、两个物种的复合体、KcsA 的 P2A/L90C 突变、K⁺ ×7、DOI；引号与文本块；坐标段不读；PDB 格式头部。模板库 7 项（授权、去重、哈希损坏、RCSB、改名与删除、存储失败、模板包往返与篡改）。`npm test` 670 项全过。
- 真实结构上的读取（4AKE、1K4C、6N2Y、6ZPO、1OMP）：结果与已知事实一致（1K4C 含 Fab 的三种聚合物；6N2Y 是 9 种聚合物、22 条链），5–47 毫秒。
- 真实浏览器（`tools/template-zone-check.cjs`）：没选授权被拒；CC BY 没写署名被拒；导入真实 4AKE.cif 后卡片显示方法、2.2 Å、物种、组成、DOI 链接、授权与备注；同一文件再导入不重复；“打开结构”能打开；**刷新后仍在**；从 PDB 编号 1AKE 添加；导出 `1AKE.glowtpl`、删除、再导入，来源只显示为“自称”；搜索；非结构文件被拒并说明原因。截图 `docs/images/workshop-my-templates.png`。

## 如实说明

- 读取器读的是文件头里**写着**的内容，不核实。分辨率取 `_refine.ls_d_res_high`（没有则冷冻电镜重构分辨率或衍射数据分辨率）；个别条目这几处与标题里写的数字不同（例如 1AKE 标题写 1.9 Å，文件里是 2.0），我们如实照文件。
- 来自 PDB 编号的模板，在这个沙箱里只用已有的夹具验证；真实联网的取回在此前的资源区流程里验证过，这里复用同一条路径。
- 模板库存在浏览器的 IndexedDB 里：清除站点数据会丢失，应该用“导出模板包”备份。Viewer 与 Studio 在同一来源下共享；在 Windows 桌面程序里是否同一来源，没有在 EXE 里验证。
- 没有读取 AlphaFold 等预测结构的置信度作为卡片信息（预测结构走此前的 `predicted-structure` 资源路径）；本地导入的预测文件会被当作普通结构处理，卡片不标“预测”——需要时下一步补。
- 没有核对用户声明的授权是否属实。我们只记录并据此决定是否允许嵌入。
