# 2026-11-20 — 4.4.1b 第二构象的小分子 + 随作品保存

## 做了什么
- **第二构象的小分子**：构象 B 的小分子用同一个拟合搬进 A 的坐标系，用 CCD 键级画成价键球棍（读不到字典就按距离推断），每个挂在“离它最近的 A 残基”所在的节点上（所以拆装时跟着动）；进度超过 0.6 才显示（沿用经典的“<0.4 看 A、>0.6 看 B、中间都不画”）。视口的 `setMolecules` 现在支持“按标签成组”和“放在节点坐标里的某个位置”（不必挂在某个小分子点上），新增 `showMolecules(标签, 显隐)`；`apps/viewer-web/ligand-geometry.mjs` 把“键 + 几何”抽成共用函数，小分子价键视图和这里共用。
- **随作品保存**：保存 `.glow` 时，第二个结构作为一个普通结构文件资产（`conformation-b`，带哈希、来源、`conformationOf`）写进包里，主结构的 `viewerState.morph` 记下资产、标签和当前进度；重新打开时自动读回、重新叠合、恢复进度和小分子，不需要再次联网。
- 换表示等重建画面后，第二状态、进度和小分子都会重新放回。

## 怎么验证的
- 全套检查见提交；本步主要靠浏览器实测（软件渲染，无页面错误），1K4C 加 5VK6：信息里写“第二构象的 9 个小分子在进度超过 0.6 时显示”；进度 1 时画面里出现通道中的 K⁺ 离子串和脂质链（`docs/images/conformation-morph-ligands.png`）；保存的 `.glow` 里确有 `assets/source.cif` 与 `assets/conformation-b.cif`；**关闭后重新打开：第二构象面板自动恢复，进度为 1，画面与保存前逐像素相同**；拉回 0 与原图逐像素相同；移除第二构象后与原图逐像素相同。

## 需要你知道的
- 经典在靠近第二构象时把“第一构象的小分子”隐藏；新版里第一构象的小分子是表面的一部分，会随插值一起移动，没有单独隐藏。
- 第二构象的保存格式是在场景里多一个结构资产，Studio 目前打开这样的作品时会把它当成一个普通结构资产（不会出错，但也不会用它做变形）。
- 还没做：两个以上的构象、按结构域/锚点配置的变形、真实路径动画；选中标记在变形时不跟着动。
