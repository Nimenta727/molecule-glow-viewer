# 2026-11-21 · 4.4.8：旋转 ATP 酶工具的第二个酶（枯草芽孢杆菌 PS3，6N2Y）

## 做了什么

1. **挑选**：6N2Y（Bacillus PS3 F1Fo，3.0 Å）——与 6ZPO（牛，c8）不同物种、不同环大小；条目里 3 条 β 链（D/E/F）、10 条 c 链（M–V）、ATP/ADP/PO₄ 都在。
2. **预设**（`plugins/atp-synthase/templates.mjs`，纯数据）：c 环 `/subunit c$/`、催化亚基 `subunit beta`、转子 `gamma chain`、`epsilon chain`、c 环；`counts.ringSubunits = 10`；步骤文字改成 c10。细菌与牛的区别写进了注释：细菌里 δ（OSCP）是静止的外周柄，转子是 γ + ε + c 环；牛的“δ/ε”（线粒体命名）则是转子的脚。
3. **端到端**（真实浏览器，`node tools/atp-second-work-check.cjs`）：Studio 导入 → 选预设添加 → 适用性检查通过 → 导出 → 全新 Viewer 打开 → 一圈 3 ATP / 10 H⁺；面板标题与证据是作品自己的；系统视图“组成（31 个部件）”。1 个固定数据条目：6N2Y 已写入 `tools/fixtures/structures.json`（3.9 MB）。
4. **端到端挖出的真问题**：Studio 导入的结构是平铺的，播放器的导航视图以转子第一条链为根，Viewer 只显示根的子树，所以只画了 γ 一条链（面板也写着“当前选择：Chain G”）。数据本身没问题（31 个节点全可见）。修法：`ensureStructureRoot`（`apps/viewer-web/work-scene.mjs`）——带工具的作品若有两个以上平铺的结构部件，补一个总根组（同 id、恒等变换，什么都不动）；已分组的、没有工具的、只有一个部件的场景不动。有单元测试；官方包本来就有总根，不受影响。
5. 测试 559 项；对照基线只因源文件哈希变化而重新生成；MBP、第二结构对、大纲三个浏览器检查重跑通过。

## 如实说明

- H⁺/ATP 的数是由环亚基数算出的教学计数，没有对 PS3 的实验化学计量另做核对；预设里的部件名称模式只在 6N2Y 上验证过。
- β 位点三个构象取自该条目自己的三个催化位点（与牛的做法相同）；没有拿别的条目的开放/紧密态。
- 这个工具仍是 player-v1；两个酶都靠“3 个 β + 一个 c 环”的结构假设，V 型 ATP 酶（不同位点数）还没试。
- 画面角度是沉积坐标系的任意角度；肉眼上 c 环与膜面的相对位置未逐项核对。
