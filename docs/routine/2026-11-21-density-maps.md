# 2026-11-21 · A2 体积数据资源

## 做了什么

- `plugins/structure/density-map.mjs`（纯逻辑）：
  - `parseMrc`：读 MRC2014/CCP4（1024 字节文件头 + 扩展头 + 体素），模式 0/1/2/6，两种字节序（按机器标记，缺失时按尺寸合理性判断），任意轴顺序（还原成 x、y、z），体素大小 = 晶胞 / 网格，原点用 MRC2014 的 ORIGIN，旧 CCP4 文件用起始索引；统计量（最小、最大、均值、均方根）。**只读直角晶胞**，复数模式、超过 3355 万体素（`MAX_VOXELS`，约 128 MB）、文件比声明短、尺寸不合理，都带原因拒绝。
  - `downsample` / `factorFor`：按整数倍的盒平均，保持范围与均值；`suggestLevel`：均值 + 3 倍均方根，**只是起点（启发式）**，保存时要标成 `heuristic`，沉积者给的推荐值优先。
  - `isosurface`：**行进四面体**（把每个立方体切成围绕主对角线的六个四面体，案例由代码算出，没有要背的查找表）；三角形朝向"低密度一侧"；`maxTriangles` 上限并报告 `truncated`；`enclosedVolume`、`surfaceArea`。
- 资源类型 `map` 带 `map` 块（`dims`、`voxelSize`、`origin`、可选 `contour { level, source: depositor|heuristic }`）：`describeMapResource`；只有 `map` 类型可以带这个块，`map` 类型必须带。

## 验证

- 单测 +10 项：浮点体积原样读回；字节序与各模式；轴顺序重排；各种拒绝；降采样；人造球体的等值面——所有顶点在球面上（1 个体素内）、体积和面积与解析值差 3% / 8% 以内、朝外；**曲面水密性**：每条边恰属于两个三角形、净面积向量为零、没有朝内的三角形。
- **这个水密性测试抓出了一个真 bug**：体素值恰好等于阈值时（球的网格点距离正好等于半径），位于曲面上的角点让三角形朝向的判断变成噪声，66 个三角形朝内，体积因此依赖原点位置（平移后体积差 9% 而不是 0）。修法：恰好等于阈值算外侧，丢掉零面积三角形。

## 如实说明

- **没有用真实 EMDB/冷冻电镜文件验证**：本环境连不上 EMDB；解析器的字段位置按 MRC2014 规范写，测试用手工构造的文件头。真实文件里可能出现的东西（扩展头里的符号数据、非标准字节序标记）只按规范处理，未实测；
- 等值面是示意级的网格（四面体剖分，三角形数约为行进立方体的两倍），不做平滑；
- 只做了读取与几何；画出来、与结构叠加、切片在 B2；
- `MAX_VOXELS` 是我按浏览器内存估的，没有在真实机器上调过。
