# 2026-11-21 · Studio 里可编辑结构域残基范围

## 做了什么

- **范围字段**：工具字段（text）可带 `format: 'ranges'`；面板显示 `1-109, 264-309`，配置里保存 `[[1,109],[264,309]]`（`packages/plugin-host/tool-model.mjs` 的 `formatRanges` / `parseRanges`）。写错给出指明哪一处的中文原因（空、`9-3`、非数字、超过段数上限），原值保持不变。`format` 只允许用在 text 字段上，描述符注册时检查。
- **两态构象工具新增字段**：各域的残基范围、参考域（下拉，选项来自当前的域）、蛋白名称正则、物种、参考配体残基名与所在链。到这里，新蛋白不靠预设也能在 Studio 里配出来（域的名称仍不能改）。
- **健壮性**：`structure.mjs` 里，没写进任何域的残基原来会让构建崩溃，现在按参考域上色并随之运动。
- **测试**：558 项（新增范围读写的往返与错误用例；内置工具“把当前值写回无变化”的测试改成用面板实际显示的格式）。真实浏览器：`node tools/mbp-work-check.cjs` 现在还会在 Studio 里先输入 `9-3`（被拒并恢复），再把 C 域改成 `114-259`，导出后 Viewer 的度量与 `state-pair` 独立计算逐位一致（36.00° / 10.65 Å）且不同于未编辑的 36.21° / 10.21 Å。
- 作者技能 `skill/references/tools.md` 同步说明预设、范围写法与 `outputs` / `dependencies`。

## 如实说明

- 域的名称仍不可改（改名会牵动参考域），需要别的名字时用预设或新建模板；
- 范围只管“作者编号”；链用蛋白字段里的链；多链复合体仍按单链处理（工具原有限制）；
- 没写进任何域的残基虽不再崩溃，但不参与域的度量，作者应让域覆盖整条链。
