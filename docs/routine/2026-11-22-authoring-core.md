## 补记：结构叠合 + 面板规矩的第五扇门“改位置”（同日）
- **第五扇门 `api.placePart`**（`packages/plugin-host/panels.mjs`）：把一整条链刚性地移到新位置，只接受单位四元数 + 两个点（绕 `from` 转、再把 `from` 送到 `to`，单位 Å，最远 2000 Å），或 `reset`；Studio 把它转成这条链对象的变换（一步撤销，不碰结构文件）。这是之前说的“叠合要先设计这扇门”。
- 面板 `org.glow.plugin.structure-superposition`（`plugins/structure/superposition.mjs` + `panels/superposition-panel.mjs`）：Horn 四元数拟合（Cα，核酸 P），配对按“作者残基编号+残基名”或（残基数相同时）按顺序；给叠合前后 RMSD、旋转角、质心平移、偏差最大的残基；可“移动这条链”“还原位置”“标出偏差 > 2 Å 的残基”“记入作品”（推导证据，写明方法和 Horn 1987）。
- 验证里最有价值的一项：真实浏览器里 4AKE 的 B 链叠到 A 链（214 对，RMSD 48.27 → 0.61 Å，旋转 178.8°），再**用导出文件里的链变换从原始坐标独立重算**，得到 0.607 Å，与面板报告一致——这证明“Å → 场景坐标 → 节点变换”的坐标换算是对的，不只是“数字看上去合理”。
- 如实写在清单里的限制：只能在**同一结构的两部分**之间叠合（两个不同条目，如开放态和闭合态，还没做）；只用 Cα、不迭代剔除离群点、不做序列比对；移动的是整条链；移动后已算好的高亮、测量、标签、界面列表仍按原始坐标；位置是计算出来的、不是测得的。

## 补记：氢键/盐桥分类 + 分子表面与静电（同日；先看了成熟软件的做法）
**对照成熟软件**：查了 ChimeraX 的文档——H 键用“按原子类型的距离+角度判据，并默认放宽 0.4 Å / 20°”，没有单一阈值；`coulombic` 默认距离相关介电 ε = 4d，单位 kcal/(mol·e)，表面外 1.4 Å 处取值，红–白–蓝（旧版 Chimera 范围 −10…+10）。PLIP 的阈值没有查到，所以疏水接触的 4.0 Å 只是常用经验值、未对照 PLIP 核实。下面的实现都按这个参照做，并写明与它们的差距。
- **分类**（`plugins/structure/interactions.mjs`，并入“界面接触”面板）：氢键 = 供体–受体重原子 2.4–3.5 Å（按残基+原子名查供体/受体表）；盐桥 = Asp/Glu 羧基氧到 Lys NZ / Arg NE,NH1,NH2 ≤ 4.0 Å（His 不计）；疏水 = 侧链碳 ≤ 4.0 Å（每对残基一条）。**没有氢原子和角度判据**，所以只是筛查，不能替代 ChimeraX 的做法；同链相邻残基跳过；Asn/Gln/His 翻转未判断。4AKE 的 A/B 链：盐桥 7、氢键 2、疏水 0。
- **原子级连线**：作品的 `bonds`（两个残基各取一个原子 + 类型）画成按类型着色的线（蓝 = 氢键，粉 = 盐桥，指到线上看距离），随作品保存，Viewer 里一样显示（真实浏览器里保存并在新 Viewer 里画出 9 条）。
- **分子表面**（`plugins/structure/molecular-surface.mjs` + `surface-draw.mjs` + 面板“分子表面与静电”）：高斯分子表面（近似 SES，不是严格 SES），每个原子一个按范德华半径的高斯；≤ 600 个原子网格 0.5 Å，更大 0.75 Å，再大自动放粗；作品里存规则 `surfaces`，打开时重新生成（Studio 和 Viewer 一致）。
- **静电着色**：简化库仑——整个结构的形式电荷（Lys +1、Arg 三个氮各 +1/3、Asp/Glu 氧各 −1/2、核酸磷酸氧各 −1/2）加通用主链部分电荷（AMBER ff14SB 数值加到重原子上），ε = 4r，表面外 1.4 Å，红 −10 … 白 0 … 蓝 +10。**不是 APBS 的泊松–玻尔兹曼结果**（没有溶剂、离子、配体电荷、pH），只适合定性比较。用解析解核对：单个 +1 电荷在 r 处是 83.02/r² kcal/(mol·e)。
- 验证：`npm test` 730 全过；真实浏览器里对 4AKE A 链：1656 个原子、82860 个三角形（0.75 Å），Viewer 打开保存的作品比不带表面的同一作品**恰好多 82860 个三角形**；三项 check 通过。表面是半透明叠加层，在 Cα 球上叠着看不太清——要看清请把该链的样式设为“隐藏”；移动过的链（结构叠合）上表面不会跟着走。
