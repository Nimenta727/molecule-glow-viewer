# 2026-11-23 · Viewer 的“查看”页、视角控制、球棍、光影包插件

## 起因
用户反馈：按钮文字被省略号截断；面板不好用；插件“没有交互入口”——亚基选择、取下、球棍/价键这些功能只能用命令，界面上没有；三维视图不能完全移动、调角度和画面中心；光影包要做成可拆卸的插件；作品只放本地。

## 做了什么
- **省略号**：经典版（`src/styles/viewer.css`）、新 Viewer、Studio 的按钮、芯片、图例、状态行改为自动换行，不再截断；面板宽度 19rem → 22rem。重新构建了 `web/index.html` 并同步副本。
- **新 Viewer 的“查看”页**（`apps/viewer-web/view-panel.mjs`，每个按钮调用一条已有命令，报错原样显示）：作用对象（全部/小分子/某条链/自己写选择）、显示方式（卡通、主链、团块、棍状、球棍、隐藏）、颜色（按链、彩虹、二级结构、疏水性、电荷、B 因子、自选色）、分子表面（单色/疏水/静电，最多 4 个）、光影、沿视线剖开（深度滑块）、亚基列表（显示/隐藏、选中、聚焦、只看它）；“拆装”（把亚基取下来）也放到这一页。
- **“视角”页**：鼠标左键模式（旋转/平移/缩放）、旋转/平移/缩放按钮、标准视角（正/背/左/右/上/下）、以所选为中心、重置；滚轮朝鼠标所指处缩放；双击画面上的点把它设为旋转中心。底层是 `viewport` 新增的 `setNavigationMode/panBy/rotateBy/zoomBy/recentre/setViewDirection`。
- **球棍样式** `ballstick`（原子球 0.4 Å + 键线，叠在卡通上，限制同棍状：一次 ≤ 300 个残基）；Viewer 新增 `surface`、`lookPack` 命令。顺带修了一个旧问题：棍状的元素颜色（如 `e05a4a`，没有 #）此前会被 THREE 当成未知颜色。
- **光影包插件** `org.glow.plugin.look-packs`（`plugins/packages/look-packs.json`）：命令 `lookPack` 归它所有，可在工坊的插件区单独停用；插件共 23 个。
- 作品留在本地：已删掉发行页上的噬菌体作品和 `phage-works-release` 工作流；0.10.0 的发行说明相应改写。

## 补充（0.11.0 发布后）：氢键与价键细节插件
- 用户要求：基础作品（模板）默认保持残基样式，但要能加上球棍、价键模型和氢键等细节；必要时先做插件。
- 新插件 `org.glow.plugin.bond-details`（共 25 个）：命令 `glow.hbonds`，“查看”页的“原子细节”四个按钮——球棍模型、价键模型、画氢键和盐桥线、清除键线。氢键（2.4–3.5 Å）和盐桥（≤ 4.0 Å）画成蓝/粉的线，最多 200 条，随作品保存；只用重原子距离，无角度。
- `interactionsBetween` 新增 `{ within: true }`：同一部分内部的作用，每对原子只算一次（此前两部分相同会因“两边共有的残基被跳过”而得到 0 条）。已加单元测试。
- 真实浏览器：2HHB 链 A 残基 1–60 画出 120 条线（共 122 条，2 个盐桥），球棍、价键在口袋（within 6 of ligands）和一段上都能画；官方模板“腺苷酸激酶（开合）”从 RCSB 载入后，“查看”页出现，球棍对全部 214 个残基和单链都有效。模板默认的残基样式不变。
- 没做到：键线是细线；氢键没有角度判据；没有真实显卡/Windows 验收。
