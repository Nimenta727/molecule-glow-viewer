# 2026-11-21 · 用平台做出第一个作品（血红蛋白）+ GPU 验收提示词

## 做了什么

1. **作品：血红蛋白——四个亚基与四个血红素**（静态作品，主题“蛋白质”，CC BY 4.0，放在工坊社区区 `workshop/community/packs/2hhb-d4e8f138-3f31-4d3f-b219-aec06f657ba8.glow`）。全程用平台，没有手改任何文件：`tools/make-hemoglobin-work.cjs` 驱动 Studio——工坊“我的模板”从 PDB 编号 2HHB 取回原文件 → “用此模板新建作品” → 给 10 个部件命名、给 4 个部件写标注（α 链、β 链、血红素、磷酸根）、写两条证据（来源数据：Fermi 等 1984 与 DOI；示意内容：命名是教学表达）、存“全貌”视角书签 → 填发布信息 → 发布检查通过 → 导出。工坊自己的 `validate.mjs` 16 个全过，`build-index.mjs` 入索引；真实 Viewer 能打开，截图 `docs/images/hemoglobin-work-viewer.png`、`docs/images/studio-hemoglobin-work.png`。
   - 每条事实都能在原文件里核对（卡片读取器读出：α 链 141 个残基 ×2、β 链 146 个残基 ×2、血红素 HEM ×4、磷酸根 PO₄ ×2、分辨率 1.74 Å、人、X 射线衍射）；背景知识（“氧结合在铁上”）单独标明“不是这个文件测出来的”。
2. **GPU 验收脚本** `tools/gpu-acceptance.cjs`：在真显卡上跑血红蛋白/ATP 合酶/呼吸链/翻译/鞭毛马达/整细胞/叶绿体、实例化 100/400/2000 份、嵌膜 40/400 份、新增命令冒烟，用 `glow.benchmark()` 测每个场景的真实帧率，输出 `report.json`、`report.md` 和截图。**软件渲染一律判“不是显卡验收”**，不会假装通过。
3. **给 AI 读的安装与验收提示词** `docs/ACCEPTANCE_GPU_PROMPT.md`：整段复制给装在那台电脑上的 AI；它会安装、跑 `npm test`、跑 GPU 验收、（Windows）跑 EXE 验收、起本地服务，并交出报告和一张“请你亲眼看”的清单。提示词的铁律：不改代码、不提交、不替你判断画面好坏、软件渲染不算显卡、失败原样记录。
4. 顺手：Viewer 里旧的“模板：只看结构…”提示改成“静态作品：…”；相关测试因社区区不再为空而更新。

## 过程中发现的真问题

- **标注归属**：Studio 的标注属于“当前选中的节点”。我第一次导出时把“概述”写在最后选中的节点上，结果概述被挂在了 β2 的血红素上，会误导读者。已去掉，概述改放在简介和证据里。用脚本导出后我读了包里的内容才发现，不是靠截图。
- **标签被空格拆开**：“X 射线晶体学”被拆成两个标签，改成“X射线晶体学”。
- **验收脚本的判定 bug**：`ok` 初值写错，所有阶段永远“未通过”（连成功的命令阶段也是）；软件渲染下按 30 fps 判定没有意义。均已修正，试跑结果见下。

## 验证

- 这个容器没有显卡，脚本用 `--software` 试跑：显卡自检（正确标成“NOT A GPU RUN（软件渲染）”）、嵌膜（40/40 与 400/400 份全部放下）、命令冒烟（结合速率 / Smoluchowski = 0.97）通过；其它阶段此前在软件渲染下跑通了流程（帧率 0.5–3 fps，没有意义）。
- `npm test`、`check-docs`、`check-copies`、`check-feature-parity` 见提交时的结果。
- **真显卡上的数据没有测过**：这正是要你验收的部分。

## 如实说明（这个作品的局限）

- **模板里读到的科研信息没有带进作品**：作品的资源记录里没有 `card`（方法、分辨率、物种等），只有我写进证据里的那句。“模板 → 作品”这条链丢了这部分信息，下一步要补。
- 作品编号是平台生成的 `2hhb-<随机串>`，不好读；Studio 现在没有“设置作品编号”的入口。
- 部件颜色是 Viewer 按链自动配的（Studio 里结构节点不能改色）；“血红素”“磷酸根”在预览里只是小方块标记，不是原子模型。作品是**静态的，没有拆开动画**。
- 作品作者署名为“Molecule Glow 项目”，授权 CC BY 4.0（坐标本身是 CC0）。是否作为正式“官方”作品由你决定；现在放在社区区，不占用 `official.` 前缀。
