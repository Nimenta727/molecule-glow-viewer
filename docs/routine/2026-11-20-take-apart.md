# 2026-11-20 — 4.4.0e 拆装（拆开 / 取下 / 装回 / 界面）第一版

## 做了什么
- **拆装模型** `plugins/structure/pieces.mjs`（纯几何，不涉及渲染）：每条聚合物链（≥3 个残基）是一块“零件”，大的在前；小分子跟着“离它最近的零件”（7 Å 内）一起动；**残基级界面**：每个残基点（Cα/P）找最近的别链残基点，8 Å（核酸 10 Å）内算界面，得到每对链的界面计数（双向）、“印记”残基（< 6.5 Å 的紧密部分）；**装配顺序**：最大的先放，之后每次放“和已装好部分界面最大”的那块（这是估计，界面上会写明）；**拆开位置** `pieceOffset(explode, pull)`：拆开程度 0 时偏移恒为 0，所以装回是精确的。
- **视口** 新增两个通用接口：`setNodeOffsets`（给节点加临时位移，记住原位置，清除即精确还原）和 `setLinks`（在两个点之间画线，随节点移动）；`setPointSelections` 新增 `markers:false`（只淡化不画金框）。
- **Viewer 的“拆装”模式**（面板里“拆装”按钮）：“拆开程度”滑块、全部拆开/装回/播放装配、每条链一个按钮；选中一条链 → 它和它的伙伴保持实心、其余淡化，并画出最近的 24 对残基连线；列出相连的链和界面残基数（“31+35”＝两边各自的界面残基数），点伙伴 → 标出两边的界面残基；“取下来 / 装回去”把一块单独抽出再放回。拆开时镜头自动后退取景。动画按真实时间推进（软件渲染帧率低也走得完）。退出或换场景自动装回。
- 顺手：`chainGroupKey`（场景节点用的链键）从表示模块导出；点“清除”时连线一起清掉。

## 怎么验证的
- 单元测试 4 项（零件/小分子归属、界面双向计数、装配顺序含预设关键字、偏移为零时精确还原）。
- **与经典代码差分对照**（`tools/pieces-parity.mjs`，报告 `docs/parity/pieces-parity-report.txt`）：8 个真实结构（含 29 条链的 6ZPO）上，零件构成与顺序、每对链的界面计数和每个残基的最近别链残基（距离差 < 1e-6）、小分子归属、贪心装配顺序、拆开/取下偏移（四组参数）全部一致，**48/48**；拆开程度为 0 时偏移恰为 0。
- 浏览器实测（软件渲染，无页面错误）：1K4C（3 块）与 6ZPO（29 块）：全部拆开画面与初始不同；选链、点伙伴、取下、装回、播放装配都有响应；**装回后、退出拆装后，画面与初始逐像素一致**（镜头复位后比较）。截图 `docs/images/take-apart-exploded.png`。

## 需要你知道的
- 新版的小分子归属沿用经典规则（最近的零件，7 Å 内）；因为新版里小分子在自己的节点里，所以拆开时按这个规则让它们跟着零件动。
- **没做**：全原子界面（从 RCSB 下载原子并判定二硫键/盐桥/氢键/疏水接触，这是验收标准里的一项）、界面“色带”（现在是细线，不是经典的圆柱带）、按亚基种类上色、预设里的装配顺序关键字、命令 API。所以这一项在验收清单里是 partial，不是完全等价。
- 没在真实 GPU 上验证。
