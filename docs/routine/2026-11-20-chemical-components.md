# 2026-11-20 — 4.4.0i 化学组件（CCD / 键级）与小分子价键视图

## 做了什么
- **化学组件模块** `plugins/structure/chemical-component.mjs`：解析 RCSB 化学组件字典（CCD）`.cif`——原子名、元素、理想坐标（去氢、居中）、键及**键级**（单/双/三，芳香键单独标记）；解析理想构型 `.sdf` 作为回退（没有原子名，不能按名字对到结构上）；`bondsFromTemplate`：把字典里的键按**原子名**对到结构里的小分子原子上，对不上的原子不画；`bondsByDistance`：没有字典时按“共价半径之和 + 0.45 Å”推断，全部当单键，离子不成键；`loadChemComp`：先 CCD，读不到再 SDF，两者都不行才报错，结果缓存；被取消的请求不会被回退掩盖（SDF 没有原子名，缓存了会破坏之后所有按名匹配）；化学组件编号先校验。联网函数是注入的，可离线测试。
- **价键几何** `packages/render-three/molecule-geometry.mjs`（纯向量计算）：单键一根棍，双键两根细棍并排，三键三根，芳香键一根棍加一条环内虚线；侧向取“相邻键所在平面”（环内方向）；有键的原子只画小关节，没有键的原子（离子）画完整的球；每根棍两半各用自己原子的颜色。
- **视口**：`setMolecules`（把小分子画在它的小分子点上，跟随所在节点，所以拆装时一起动）、`focusPoint`（镜头移到该点并按分子大小取景）。
- **Viewer**：选中一个小分子（点它，或选择语言恰好选中一个）后出现“显示价键结构”：画出带键级的球棍，镜头靠近，其余部件淡化；说明里写出来源——“键级来自 RCSB 化学组件字典（单键 20、双键 3、芳香键 10）”，读不到字典或名字对不上时明说“键由原子间距离推断，全部画成单键”。再点一次隐藏并恢复镜头。选了别的内容会自动收起。

## 怎么验证的
- 单元测试 10 项（化学组件 6：ATP 的原子名/元素/键级/芳香标记、离子与血红素、按名匹配与缺失原子、距离回退与离子不成键、SDF 回退、加载顺序/缓存/取消/非法编号；几何 4：键级对应的棍/虚线数量、双键平行且在相邻键平面内、关节与离子球与缩放、退化键）。
- **与经典代码差分对照**（`tools/chemcomp-parity.mjs`，报告 `docs/parity/chemcomp-parity-report.txt`）：原样运行经典 `getTemplate`、`bondsFromTemplate`、`bondsOf`、`buildMolecules`（价键样式），喂同样的 CCD 记录和 8 个真实结构里的全部小分子：ATP/HEM/F09/K 的模板原子（名字、元素、居中理想坐标）和键级逐项一致；SDF 回退一致；8 个结构的所有小分子的距离推断键一致；真实结构里的 ATP、F09 按名匹配到的键一致（ATP 33 个）；价键绘制（关节、棍、虚线的位置，float32 容差 1e-3 Å）一致。**91/91**。（对照中发现并修正了脚本自身的一个缺陷：SDF 回退测试残留的缓存会让后面按名匹配用上无名字模板。）
- 联网浏览器实测（软件渲染，无页面错误）：1K4C 的 F09（脂肪酸）→ 单键 9；6ZPO 的 ATP → 单键 20、双键 3、芳香键 10（与字典一致）；再点隐藏后画面与之前逐像素相同；选多个小分子时控件收起。截图 `docs/images/ligand-valence-atp.png`。

## 需要你知道的
- 这一步只做了“字典 + 价键视图”。经典的**结合位点视图**（周围残基、相互作用线）、**口袋**、**测量距离**、其他小分子样式（球棍、空间填充）、动画里的模板分子都还没迁，`structure.ligand-analysis` 仍标 partial。
- 新版直接用结构自己的原子，不用像经典那样为了结合位点再下载一份坐标；结合位点视图会沿用这一点。
- 没在真实 GPU 上验证；字典读取在桌面版依赖网络策略（`files.rcsb.org` 经典版已在用）。
