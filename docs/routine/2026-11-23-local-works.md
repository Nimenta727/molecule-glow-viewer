# 2026-11-23 · 作品的导入导出优化与工坊“本地”区

## 用户要求
优化导入和导出文件；一旦导入，在创意工坊里加一个“本地”选项，并且必须显示作品名称。

## 做了什么
- **本地作品库** `plugins/workshop/local-works.mjs`：打开或导入过的 .glow 作品记在本机（IndexedDB，`glow-local-works`），记录名称（作品标题）、原文件名、大小、时间；同一个文件只记一份（按 SHA-256），再导入只更新名称并排到最前；读回时核对哈希；可改名、删除；存储失败会用一句话说明，不留半份数据。上限 128 MB（与场景包上限一致）。
- **工坊“本地”区** `plugins/workshop/local-zone.mjs` + `dialog.mjs`：新标签“本地”，每个作品显示**名称**（作品标题）、文件名、大小和时间，按钮：打开、导出、改名、删除；顶部“导入 .glow 文件…”；可搜索。不依赖工坊目录，离线也能用。Viewer 和 Studio 都有。
- **导入优化**：
  - Viewer：选文件或**把文件拖到页面上**都走同一条路；先检查文件类型（.glow/.json/.cif/.pdb/.mrc 等）和大小，不支持或太大时说清楚；超过 8 MB 时提示“大文件需要一会儿”；打开成功后自动记入“本地”，状态栏显示名称和大小。
  - Studio“导入场景包…”：先查扩展名和大小，再读；成功后记入“本地”；导入逻辑拆成 `importPackageBytes`，“本地”区的“打开”也用它。
- **导出优化**：Viewer 的“保存”、Studio 的“导出场景”和发布包，文件名改用**作品标题**（去掉 Windows 不允许的字符，中文保留），不再是一串编号；导出后状态栏显示文件名和大小。

## 检查
- 单元测试 `plugins/workshop/test/local-works.test.mjs`（文件名、去重、排序、哈希核对、改名、删除、损坏/缺失/过大、存储失败回滚）。
- 浏览器检查 `tools/local-works-check.cjs`：Viewer 打开 `t7-capsid-gp10a.glow` → 状态栏“已打开‘T7 噬菌体成熟衣壳的主衣壳蛋白 gp10A…’（4.0 MB），并记入工坊的‘本地’”→ 工坊“本地”里按名称列出 → 导出文件名就是作品标题 → 改名 → 从“本地”重新打开 → 删除；`STUDIO=1` 时在 Studio 里导入并从“本地”重新打开。页面无报错。
- 顺带发现：无头浏览器把中文下载文件名报成 “download”，所以检查改为读页面请求的文件名；真实浏览器/桌面版的保存对话框里应是中文名，**没有在真实 Windows 上看过**。

## 没做到 / 要注意
- “本地”里存的是一份副本（在浏览器/桌面版的本机存储里），大作品会占同样大的空间；删除只删这份副本，不动硬盘上的原文件。
- Studio 还没有拖放导入。
- 没有在真实 Windows 上验证。
