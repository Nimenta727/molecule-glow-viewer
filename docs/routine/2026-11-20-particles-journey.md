# 2026-11-20 — 4.4.2b 行进与事件（纯逻辑）

## 做了什么
- **新模块 `plugins/motion/journey.mjs`**（纯状态机，无 Promise、无页面），提取经典的 `travel`、`eventTag`、`protonAcross` 和 `anim-runner.js` 的时间推进：
  - `Journey`：一个粒子沿一段或多段曲线走；淡入/淡出、缓动、翻滚；一段结束的那个 tick 不带走余下时间，下一段下一个 tick 才开始；后一段的路径在开始时才计算（随机数的取用顺序与经典一致）。
  - `Motion`：调度器，`clear()` 一次取消全部（场景清空时不留下仍在跑的行进，也不触发任何回调）。
  - `EventLog`：带时间的事件日志（去掉标记，保留最近 500 条）和会随时间消失的事件标签。
  - `membraneCrossing`：质子/离子过膜（入口侧池 → 通道口 → 通道 → 出口 → 出口侧池，或没有出口池就直接离开）；沿用经典的节奏参数（`tIn/tChan/tOut`、`pace`）。
- 登记：验收清单里的 `motion.particles-paths-flow` 增加这部分证据。
