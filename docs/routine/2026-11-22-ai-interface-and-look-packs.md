# 2026-11-22 · 给 AI 的 Studio 命令接口、实时过程页签、光影包与三个展示作品

## 做了什么
- **`window.studio` 命令接口**（`apps/studio-web/studio-commands.mjs`，队列共用 `apps/viewer-web/command-api.mjs`）：作图和分析的每一步都是一条带校验的 JSON 命令——import / addStructure / select / show / color（可指定哪个结构）/ surface（可带颜色）/ measure / label / contacts / composition / secondary / superpose / parts / part / camera（含 `focus`）/ cameraKey / lookPack / note / title / publication / undo / redo / snapshot / exportScene，以及自描述的 `help()`。分析命令默认只算不写，`write` 里写明才写进作品，并且都走面板规矩的五扇门；每个分析的回包带 `limits`（静电不是 APBS、氢键/盐桥无角度、叠合只用 Cα……），转述时必须带上。
- **实时过程页签**（`apps/studio-web/process-log.mjs`）：AI 通过命令接口做的每一步实时显示（命令、参数、结果、成败），可“跟随 AI 切换页签”、可把演示速度放慢（每步 0.5/1.2/2.5 秒）、每一步旁有“回到这一步前”（撤销到那一步及之后）。专业制作者随时可以接手修改；日志只是显示，不改变命令或回包（`createCommandApi` 的 `onEvent`/`pace` 钩子）。
- **光影包**（`plugins/structure/look-packs.mjs`，渲染 `packages/render-three/glow-style.mjs`，`viewport.setLook`）：四个包——暗场·细胞内部、冷光·膜蛋白、暖光·活性位点、论文白底；数据只含背景/雾/遮蔽/轮廓光/景深/曝光/光照和按类别的配色规则，保存在作品里（`viewerState.lookPack`），Studio 和 Viewer 一样画。我对着截图反复调过：色彩空间（表面顶点色要转线性，否则发白）、环境遮蔽的圈状伪影（逐像素旋转加深度感知平滑）、表面要写入深度缓冲（遮蔽和景深才对）、三角形朝向统一向外（实心表面隐藏背面）、光照对比与轮廓光强度。
- **分子表面**：能画核糖体级别（单个表面最多 25 万个原子，粗网格），颜色可由规则给定。
- **多结构的外观**：颜色规则可以指定属于哪个结构（`structure`），所以开放态/闭合态能分色；样式、表面、标注仍只作用在第一个结构上。
- **三个展示作品**（`tools/make-showcase-works.cjs`，只用 `window.studio` 做）：70S 核糖体（4V9H，暗场，rRNA 红 / 蛋白紫；因文件太大——约 22 MB——没有放进仓库，脚本可复现）、血红蛋白 2HHB（暖光，α/β 表面 + 界面分析并记证据，已入工坊社区区）、腺苷酸激酶开放/闭合（白底，核心域叠合 RMSD 1.975 Å，蓝/橙分色，已入工坊社区区）。
- **Skill**：新增 `skill/references/studio_authoring.md`（操作手册 + 制作规范：诚实、来源与可复现、配色与光影、与专业制作者协作、交付前核对），SKILL.md 与 platform.md 已指向它。

## 验证
- `npm test` 742 全过；`tools/studio-api-check.cjs`（只用命令接口做完整作品，导出后独立重算 RMSD 1.975 Å，并检查过程页签与“回到这一步前”）、分析面板、外观检查通过；三个作品都在 Viewer 里打开核对过（光影、表面、颜色一致）。
- 光影的评审靠截图对照参考图和反复调参，不是定量验证；软件渲染下完成，真实显卡上的观感和帧率未验收（一个核糖体亚基的表面有几十万个三角形）。

## 没做到的（如实）
- **没有做“一群分子拥挤在一起”的场景**（参考图那样几个核糖体加伴侣蛋白、带景深虚化的背景），也没有做图里的扩散系数曲线小图：需要给结构做多份拷贝/摆放（实例化）和图表叠加，目前只有单个复合体的展示。
- 暗场景的“胶片质感”（体积光、真实的次表面、抗锯齿的毛发细节）达不到参考图；表面是高斯近似，不是严格的 SES。
- 后加入的结构不带样式规则、表面和标注；叠合移动过的链上表面和标注不跟着走。
