# 2026-11-20 — 4.4.0c 未选中淡化

## 做了什么
- 视口新增淡化：用选择语言（或序列条拖动）选中一批残基后，**没有任何选中对象的部件**变成半透明虚影，不再写深度（所以墨线轮廓消失），轮廓壳隐藏；选中的部件保持原样并带金色线框。与选中部件共用的材质不会被误淡化。清除选择或换一次选择就还原。
- 淡化的粒度和经典一致：按“部件”（这里是一条链/一个节点），不是按残基。所以选的残基所在那条链仍是实心，其他链变淡；只有一个部件时没有东西可淡化；选“全部”也不淡化。
- 改动：`packages/render-three/viewport.mjs`（`setPointSelections(targets, { dim })`、`dimOtherNodes`、`restoreDimming`），`apps/viewer-web/main.mjs` 选择集开启淡化。

## 怎么验证的
- 全套检查见提交（Node 测试、文档、验收清单、构建一致性）。
- 浏览器实测（软件渲染，无页面错误），4AKE：选 `chain A and resi 10-60` → B 链变虚影、A 链实心；选 `all` → 不淡化；选 `none` 或 `chain B` 后再 `none` → 画面与最初逐像素一致（截图哈希相同）。截图 `docs/images/selection-dimming.png`。

## 需要你知道的
- 单个残基的鼠标点选、机制步骤里的选择暂时**不**触发淡化（避免改变现有画面）；之后若要统一，需要决定点选是否也淡化其余部件。
- 没在真实 GPU 上看过；`structure.sequence` / `selection.full-language-sets` 在验收清单里仍是 partial。
