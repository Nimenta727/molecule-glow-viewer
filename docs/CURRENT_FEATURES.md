# 现有功能

目标产品分为主体、功能插件、资源和作品：插件提供工具，原始蛋白结构进入工坊资源区，动画/功能演示和分析成果进入作品区。优先级为制作基底→经典已有功能插件化→新增科研插件；经典已有分析也优先恢复。该分区与完整制作路径尚待实现；现有 ATP/KcsA/AdK 专用模块仍需拆分。详见 [架构](ARCHITECTURE.md)。

**最新状态见 [STATUS](STATUS.md)**：下表“新主体＋插件”一列写于 4.4 之前，粒子/数据反应/随机门控/翻译/多过程已由 `org.glow.tool.*` 五个通用工具提供（均经典对照），其余格子仍按下表。

以下按入口评价当前能力；源码、经典对照、科学有效性、视觉和产物分别验收。[机器清单](feature-parity.json)给出逐项契约。

Studio 已有多场景工程、对象/变换、关键帧、讲解、证据、镜头书签、工程重开和 v2 导出。Core/Schema 提供事务状态、加载取消、生命周期和 ZIP 校验；插件来自受信应用目录，社区包不提供可执行代码。

15 个官方 v1 包的数据校验和结构兼容已经恢复；只有已安装对应播放器的过程获得动态行为。ATP/KcsA/AdK 的选定对照包括 19 行解析/相位、5 行坐标/质子结果，不代表完整科学等价，见 [科学卡](science/README.md)与 [数值基础](parity/README.md)。
