## 1. 执行原则与当前进度

- 主体是制作与运行基底；插件实现功能，涵盖制作、动画、模拟及分析；蛋白等是资源，线粒体等是作品。工坊分资源区/作品区。
- **先完成制作基底，再优先恢复 Claude 经典版已有功能并按功能插件化，之后做新增科研插件。** 不为每个作品创建内容插件，不仅迁科研能力，也不能只提供预设播放。
- 经典已有测量/口袋/界面/序列/定膜等也要优先恢复；不能因其属于分析就推迟到新增科研阶段。
- 作品用作能力验证与示例，随着功能工具交付；制作一套作品不能代替工具可复用和作者可操作的验收。
- 本轮只更新文档/计划。下一项为 **4.3.0**，4.3–4.7 均未整体完成，不因文档已写就勾选。

## 3. 4.4 — 经典功能优先，按功能拆专用插件

以下组是功能交付边界；最终物理包可按实际依赖合并/拆分，不预先制造十套独立引擎。工具保留专业适用条件，不能把所有科学模型削成简单运动。

| 编号 | 功能组 | 经典范围及必须保留内容 |
|---|---|---|
| **4.4.0** | 结构表示、选择与操作 | 五种表示及经典缺项、CCD/键级、着色/剖切、完整选择语言/集合、序列身份与子单元/配体绑定 |
| **4.4.1** | 构象与对象动画 | 叠合/对应、域/轴/锚点配置、插值、旋转、路径和联动；先提取 AdK/ATP 现有能力并保留两态/计数差异 |
| **4.4.2** | 粒子、路径与流 | 池、布朗/定向运动、避障、名称、跨膜/区室流及视觉时间尺度；不能有未命名粒子 |
| **4.4.3** | 数据反应与区室模拟 | v1 compartments/species/pools/flows/reactions、输入输出计量、浓度/pH/膜电位、守恒、种子/时钟、参数与事件；AdK 反应和 KcsA 数据作品作为用例 |
| **4.4.4** | 门控/动力学与观测 | 可配置门控、通量、阻断、区室粒子/水合、计数/电流/浓度曲线；提取 KcsA，区分数学模型与作品配置 |
| **4.4.5** | 序列与随机状态过程 | tRNA/序列步骤、随机事件、药物/浓度响应、seed、时钟及单位；用翻译作品验证，不建核糖体内容插件 |
| **4.4.6** | 环境、多过程与跨尺度 | 膜/朝向、拥挤环境、多过程独立状态、跨尺度实例/进入返回；细胞一角/全细胞为验收作品 |
| **4.4.7** | 经典分析与教学工具 | 测量、接触、口袋、界面、拆装、域运动、自动简介/定膜、功能位点；字幕/证据/能量条/标签/书签、曲线与步骤讲解；可按依赖分批落地 |
| **4.4.8** | 经典作品与能力组合回归 | 将 ATP/KcsA/AdK、呼吸链、光反应、鞭毛、翻译、细胞一角/全细胞迁为资源＋作品配置；逐项补齐缺失能力、15 包行为与经典专项对照 |

作品可随前面各工具同步制作，4.4.8 是集中验收而非开始制作作品的时间。呼吸链仍核对 Q 循环/电子与质子账本/抑制剂及 3/8 计量，光反应仍核对 NADPH/ATP/光强与区室约束；旧计划的科学要求继续有效。完整功能继承契约见 [feature-parity.json](feature-parity.json)，原始细项见 [Claude 交接原文](history/CODEX_MIGRATION_HANDOFF_2026-11-18.md)。

**4.4 完成门槛**：每组既有经典行为/科学证据，也有作者配置、同一工具复用于不同适用输入、确定性/保存重开/停用释放证据。作品标题不是插件 API；导入任意结构不意味着能自动判断真实机制。

## 5. 4.6 — 新增科研插件（在前述能力之后）

- 先确认真正需要的新分析任务、输入与方法，不预先承诺某个外部算法或数据库集成已经实现。
- 通过同一功能工具协议接入；结果携带来源、资源哈希、算法/版本、参数、单位、误差与限制，保存在作品/分析记录中，不覆盖原始资源。
- 专业判断与教学运动区分；科学有效性与软件确定性分别验收，必要的实验/专业审阅明确列为待办。
- 经典已有测量/口袋/序列等归 4.4；本阶段不是延迟恢复这些功能的理由。

## 6. 4.7 — 性能、发行与最终交接

低画质/GPU-less、自适应分辨率、大结构限额/进度、快速切换、重复加载和释放贯穿各阶段；此处执行全量性能/科学/行为对照，列真实 GPU 与软件渲染环境。Web/源码/桌面标识、Pages 新版预览策略、实际 EXE、Skill 与可复验清单同步。

Codex 完成制作基底所需接口/编辑与功能拆分、经典迁移、作者/工坊路径及验收；不把可操作的制作功能全部留给最后。Claude 原交接中的最终画风/布局/开场、全面前端去重、完整沙箱及制作区整体体验收尾继续单列；最新维护者范围优先。经典实现保留作回退，待有等价证据再决定退役。

## 7. 统一验收与完成条件

每项绑定当前源提交、经典/新版用例、真实或明确合成的输入、预期/容差和可复验记录。功能、经典对照、科学有效性、视觉、产物状态分开，不用一项“已完成”覆盖。

| 维度 | 必须核对 |
|---|---|
| 制作/复用 | 导入→工具配置→预览→可编辑保存/重开；另一适用资源/作品复用同一功能，无需改工具源码 |
| 科学 | 物种/突变体、来源/原始哈希、实验/推导/模型/示意、方程/单位、计量/守恒与数值差异 |
| 时间/随机 | 固定步进/seek/重放、参数历史、seed、模拟/演示时钟差异；不强求不同模型同种子逐事件一致 |
| 状态/安全 | 资源不可变、作品/实例独立、依赖精确、无包内脚本；失败/取消不污染当前工程，权限拒绝/撤销有效 |
| 生命周期 | 停工具/换作品释放请求、监听、Worker、播放器与 GPU 资源；缺依赖有明确降级说明 |
| 交互/产物 | 宽窄截图人工检查；适当 Node/包测试、CI、暂存与真正 EXE；历史通过不冒充本提交复测 |

全部经典契约和作品行为验收或有维护者明确取舍，制作/复用与工坊路径贯通，差异/证据/维护者动作齐全，才生成最终 MIGRATION_REPORT.md 与 migration-complete 标签。新增科研插件按另行明确的范围验收，不以无限未知功能作为经典迁移完成条件。
