# 四种展示模式 M1

在新版 Viewer 点击「四模式示例」，或用「打开」载入 [M0 示意场景](../apps/viewer-web/four-modes-demo.glow)。细胞视图可点击浅绿色传递区选中热点，再通过「进入局部系统」进入。局部系统可进入蛋白质或反应机理。蛋白质也有机理入口。面板显示场景、当前位置和选择，标注列表随当前位置更新。

点击「返回上一级」或按 Esc，恢复调用者的选择和镜头。进入、返回后键盘焦点移到当前视图标题，可继续按 Tab 操作。「重置视角」恢复当前视图的默认取景并保留选择。系统启用减少动效时，镜头直接到达目的地。窗口缩放时，共用视口会按新的宽高比调整取景和画布。

## 实现

- `apps/viewer-web/scene-navigation.mjs` 管理当前场景的路径、入口和选择。机理返回实际调用者。Viewer 通过已有加载协调器提交导航状态。替换和关闭会释放旧场景，加载失败时保留上次成功提交的场景及路径。
- `packages/render-three/viewport.mjs` 提供节点取景和可取消的镜头过渡。导航复用当前场景的几何体和播放状态。连续操作用最新镜头目标覆盖旧过渡，返回使用进入前保存的镜头目标。按钮、画布和键盘监听器在 Viewer 生命周期内注册一次。
- 普通场景继续使用原有打开、播放和重置流程。机理步骤界面、模式专用面板和步骤同步属于 M2。

## 复验

设置 `GLOW_M1_SCREENSHOTS` 为截图目录，用 Electron 启动 `tools/studio-smoke.cjs`。脚本覆盖画布热点拾取、两条机理入口、选择和镜头恢复、连续进出、减少动效、窄窗口键盘入口、加载失败、文件替换及关闭。脚本检查过渡后的动画帧归零、进出过程中不新增几何缓冲区，以及关闭后释放已记录的几何缓冲区。普通和窄窗口截图输出在该目录。

同时设置 `GLOW_M0_SCREENSHOTS` 可重跑保存重开、旧文件兼容及无结构插件验收。

本轮通过 Electron 的 M0、M1 验收与 74 项 Node 检查（`node --test packages/*/test/*.test.mjs plugins/*/test/*.test.mjs`）。经典 Viewer 构建和副本一致性通过。560 像素宽度下，画布随窗口调整，键盘可进入局部系统，返回按钮和播放控件可操作。
