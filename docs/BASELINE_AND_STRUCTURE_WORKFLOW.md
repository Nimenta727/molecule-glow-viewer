# 基线与结构工作流实施清单

本文落实整体计划的第 1、2 项：冻结经典 Viewer 的产品行为基线，并定义新版主体的真实结构端到端工作流。它是实施清单，不表示下列尚未验证的交互已经在新版 Viewer 完成。

## 1. 产品基线

### 代码入口

- 经典 Viewer 源码：`src/`；构建产物：`web/index.html`；构建命令：`node tools/build.mjs`。
- 新 Viewer：`apps/viewer-web/`；结构解析与表示原型：`plugins/structure/`；RCSB 插件：`plugins/rcsb/`。
- 经典体验范围包括结构载入、三种蛋白表示与插画风格、配体聚焦、残基/部件交互、证据与字幕、场景/机制控制，以及 `window.glow` API。

### 行为基线清单

| 区域 | 需要记录的基线行为 | 新主体继承要求 |
|---|---|---|
| 启动与载入 | 预设、PDB 编号、本地 PDB/mmCIF、加载错误与取消 | 同一入口可调用结构能力；失败可恢复且不留下半载入场景 |
| 视口 | 默认白底插画、旋转/缩放、重置、聚焦与过渡取消 | 镜头状态统一；切换导航后能恢复原视角 |
| 表示 | 团块、结构示意、简化示意、部件可见性 | 表示可切换，配色、图层和低性能降级保留语义 |
| 选择 | 残基/部件/配体点选、背景淡化、信息卡、Esc 取消 | 选择事件保留结构 ID、链、auth/label 编号、插入码与配体 ID |
| 教学信息 | 图例、标签、证据、字幕、步骤与能量条 | 导航/时间线操作不清除这些状态 |
| API 与嵌入 | `window.glow` 命令、命令日志、嵌入消息 | 维持命令语义和来源校验，统一转发到新场景状态 |
| 窗口适配 | 桌面宽屏与 560 px 窄窗口的控件可达性 | 两种尺寸下关键功能可操作，布局和镜头稳定 |

## 2. 真实结构端到端工作流

### 用户路径

1. 用户从 RCSB 输入 PDB 编号，或拖入本地 PDB/mmCIF 文件。
2. 导入器保留原始字节、来源、文件名/编号和格式；解析结构模型并提供链、残基、原子、配体与来源元数据。
3. 主体调用结构表示能力生成初始视图；用户可切换表示、点选残基或配体。
4. 选择驱动信息卡和镜头聚焦；配体选择进入结合位点视图，并提供接触信息入口。
5. 用户保存场景为 Glow 包，关闭后重新打开；结构、来源、视图、表示和选择相关持久化状态按格式约定恢复。

### 数据与交互契约

- 结构实例有稳定 ID；链、残基和配体对象使用稳定对象 ID，并保留 author 与 label 编号映射及插入码。
- 解析结果与原始资产分离保存，记录来源 URI/编号、格式、哈希和解析器版本；网络资源需支持取消与缓存策略。
- 表示能力接收结构模型、视口和场景配置，返回可释放的渲染层及拾取映射；结构插件卸载或场景替换时释放 GPU 资源与监听器。
- 拾取结果通过统一选择事件送达信息面板、相机和后续分析服务，不由渲染器直接改写多个 UI 状态。
- 外部 PDB 下载失败、格式错误、空结构和不支持字段都显示可理解的错误；保留原文件/场景数据，不生成误导性的空白成功状态。

### 分阶段交付

| 交付 | 完成条件 |
|---|---|
| A. 导入闭环 | RCSB 编号与本地 PDB/mmCIF 均可导入；原始数据、来源、链/残基映射可查询 |
| B. 显示闭环 | 初始结构可显示；基础表示切换可用；模型重载和取消不残留旧图层 |
| C. 选择闭环 | 点选真实残基/配体返回正确身份；信息卡及镜头响应；Esc 清除选择 |
| D. 持久化闭环 | 保存并重开后结构与来源一致；包内资产和外部 accession 两条路径均有定义 |
| E. 兼容闭环 | 经典预设行为作为对照；缺失插件或网络时显示明确诊断，不静默丢失场景信息 |

## 验收记录模板

每个验收样例记录：结构来源与编号/文件哈希、链与目标残基/配体、导入结果、表示、选择结果、镜头行为、保存重开结果、错误/降级提示、浏览器或桌面版本、截图位置。至少覆盖一个 RCSB 条目和一个本地 mmCIF；PDB 本地文件可作为补充格式样例。

Electron 33.4.11 测试覆盖了真实 RCSB 4HHB 导入、本地合成 PDB/mmCIF 导入、点击 HIS（作者 A:8B，标签 X:2）和 HEM（作者 A:101）、Esc、表示切换、最近重原子距离，以及坏文件和快速切换时保留有效场景。保存重开验证了字节、SHA-256、来源、表示和选择，镜头随场景保存。停用插件后重开仍可显示包内预览。检查了 4HHB 墨线团块的 [1440 px 宽屏](images/viewer-4hhb-blob-normal.png) 和 [560 px 窄屏](images/viewer-4hhb-blob-narrow.png)。

设置 `GLOW_STRUCTURE_SCREENSHOTS` 为输出目录，用 Electron 运行 `tools/studio-smoke.cjs` 可复验。另设 `GLOW_LIVE_STRUCTURE_SMOKE=1` 切换到真实 RCSB 下载，并逐个检查官方包，输出 `official-v1-report.json`。

带字幕、部件讲解或旧证据字段的包可以在「标注、证据与视角」查看相应内容。

多结构复验覆盖 5 个声明 `components` 的官方包，共 13 个附加组件条目。叶绿体光反应加载了 6 个组件，鞭毛马达恢复了 11 个定子副本和 130 个鞭毛丝副本。呼吸链和叶绿体使用正对复合体排列方向的初始镜头。针对找不到相应名称、由过程决定位置或超出容量的组件，查看器会给出诊断。ATP 合酶包已可播放，其余专用过程继续显示可用结构并提示能力需求。

本地 Electron 用合成 v1 场景复验了三个环形副本、指定配色、隐藏部件与简化表示。保存为 v2 后关闭重开，组件节点和变换保持一致；切换「部件显隐」中的可见性或表示后，保存会保留对应设置。

生物组装体验收覆盖 mmCIF 操作列表与组合、PDB `REMARK 350`、缺少组装说明时的原始坐标回退、原文件字节保持以及 v2 重开。真实 [1K4C 组装体 1](images/viewer-1k4c-assembly.png) 展开得到 18,136 个原子与 12 条聚合物链。15 个官方旧包复验均显示了主结构及全部声明的附加组件。

在 [4HHB 的 560 px 截图](images/viewer-4hhb-functional.png) 核对了功能分区的初版。第二阶段收尾将粗分组外形换成经典 Gaussian 密度与 surface nets 表面，使用 12 Å 分辨率、每个蛋白残基 136 Å³ 的目标体积。配体重原子 8 Å 邻域及场景指定核心保留代表点。缺少核心和运动声明的支架采用淡色。单部件表面、功能分区、团块和结构示意可通过官方结构插件切换。

在实际 6ZPO 组装体 1 上，按旧 ATP 合酶预设的残基范围和指定邻域规则生成了 416 个核心代表点。只计算配体邻域时为 326 个。

## ATP 合酶播放器验收

第三阶段使用官方 6ZPO 场景包。播放器以同一个结构显示 c8 环及中心柄旋转，并用三个沉积 β 亚基的坐标对齐、插值生成构象变化。表面通过代表残基的位移场随构象变化。粒子名称、反应、膜和时间均在界面标明为教学示意。核苷酸形状取自输入坐标，路径与磷酸示意按教学模型生成。

确定性检查覆盖固定步进与直接跳转的一致性、同种子重放、暂停、转速变更、播放状态保存重开及插件卸载。完整一圈得到 8 H⁺ 和 3 ATP。转速变更记录在状态中，倒回会重现原来的进度。播放倍率独立于转速。

Electron 实测通过了表面/功能分区切换、播放与暂停、单步、拖动进度、五个能量步骤、种子重置、转速、状态保存重开、从系统或蛋白质进入机理后返回，以及播放器停用后的结构预览。对应截图为 [低分辨率表面](images/atp-surface.png)、[机理与控制面板](images/atp-mechanism.png) 和 [560 px 控制面板](images/atp-mechanism-narrow.png)。使用 `GLOW_ATP_SMOKE` 复跑；设置 `GLOW_ATP_CIF` 可复用已从 RCSB 下载的相同真实坐标。

新版插件宿主提供受信 `players` 与声明式 `panels` 注册点。场景替换、关闭和插件停用都会清理播放器、粒子几何、纹理和渲染资源。Studio M3 原有的工程重开、导出、导航和时间线回归通过。其他经典过程、旧命令兼容接口和 Studio 领域作者工具继续按第四、第五阶段推进。

## 第四阶段首批：命令与嵌入

新版入口已提供 `window.glow` 的基础命令、串行执行、失败恢复和日志重放；操作转发到现有场景、结构插件与 ATP 播放器。消息桥保留 `glow: cmd/reply/ready` 格式，需显式启用并匹配受信来源。完整参数、差异和待迁移能力见 [命令接口说明](VIEWER_COMMAND_API.md)。本批不代表第四阶段整体完成。

Electron 实测覆盖了本地 mmCIF 的作者 A:8B / 标签 X:2 选择、表示切换、错误参数和不允许的远程来源、v2 导出校验及重开。重开后镜头、表示和选择一致。PNG 截图与 1440/560 px 窗口截图已人工查看。实际 6ZPO 回归额外验证命令定步 180 × 1/30 秒和直接跳转 6 秒的计数一致，种子、播放暂停及失败命令不改变播放计数。96 项 Node 测试、构建/副本检查和 15 个官方包校验通过。

后续按其他机制插件（先 KcsA，再 AdK 等）、复合系统、拆装与分析、工坊、其余接口兼容逐项推进；每项分别记录科学数值和界面验收。

## 第四阶段第二批：KcsA 机制插件

`org.glow.legacy-process.kcsa@1.0.0` 已接入新版主体。官方目录统一选择 ATP / KcsA 播放器，宿主按声明生成领域参数面板；渲染器只接收构象权重、粒子与变换。旧包中的 `process: kcsa` 自动进入该插件，继续使用同一个场景、时间线和四模式导航。

使用 RCSB 原始 1K4C / 5VK6 / 5VKE / 2HVK / 2ITD 文件和组装体 1。通道孔区作者编号 60–80、四链的 24 种排列叠合得到 0.428 / 0.666 / 0.080 / 0.247 Å RMSD。过滤器、中央腔和阻断剂均取沉积位置；开放态的粗粒度孔道搜索生成进出路径。中间构象、粒子插值和膜明确标为教学模型。截图：[功能分区与控制面板](images/kcsa-functional.png)、[560 px 数值与参数](images/kcsa-controls-narrow.png)。

保留经典门控/失活、TBA/Ba 结合解离及四态敲击速率，并显示瞬时导电电流、开放未阻断模型电流、E_K、累计内/外流、Na 排斥和两种模拟时间。门控时钟与渗透时钟可分别调节，显示插值不阻塞模拟时钟。128 个种子的集合通量与开放时钟的解析电流相符；对称浓度电导在 80–120 pS 范围，140/5 mM 时反转电位为 −85.6 mV。中性 pH、失活和两种阻断剂均降低通量。

Electron 33.4.11 已验证真实四聚体的团块、cartoon、密度表面、功能分区、步骤检查、参数输入、暂停/播放、固定步进与跳转、反向净通量、机理进入/返回及插件卸载/重启。导出 v2 包含五个原始坐标；重开没有再次下载，计数、参数干预记录与模拟时钟一致。开放结构下载失败时保留可见静态结构、显示原因，不写入部分构象资源。设置 `GLOW_KCSA_SMOKE=<目录>` 运行 `tools/studio-smoke.cjs` 复验；可用 `GLOW_KCSA_CIF_DIR` 指向相同 RCSB 文件。

104 项 Node 测试通过，ATP 真实结构回归和基础命令/嵌入回归通过，经典构建、副本一致性及 15 个官方包校验通过。KcsA 的体相区室粒子、水合层和曲线尚未迁移，开放坐标为 E71A；野生型开关改变失活动力学。具体范围见 [插件说明](../plugins/kcsa/README.md)。下一项为 AdK；第四阶段整体仍在进行。

## 第四阶段第三批：AdK 两态构象插件

2026-11-19 完成 `org.glow.legacy-process.adenylate-kinase@1.0.0`。官方 `adenylate-kinase` 包原本没有 `process` 字段，宿主按其明确的 `4AKE / 1AKE` 状态声明选择受信播放器，兼容转换添加可选依赖；保留原场景字段。AdK、KcsA 的异步准备通过统一返回值传递构象输入，主体不再指定某个过程的模型缓存。

使用 RCSB 4AKE 张开态和 1AKE Ap5A 抑制剂闭合态，A 链 214 个 Cα 完整匹配。以经典 CORE/NMP/LID 范围分域，并在 CORE 上稳定叠合，RMSD 为 1.975 Å。相对张开态 CORE，闭合端 NMP 转动 44.82°、移动 9.79 Å；LID 转动 52.16°、移动 14.38 Å。中间形状与域配色为教学表达，实测 Ap5A 参考仅在闭合端显示。截图：[张开态](images/adk-open.png)、[闭合态与 Ap5A](images/adk-closed.png)、[560 px 控制与说明](images/adk-controls-narrow.png)。

手动构象滑块、自动往复、变速、固定步进、四个讲解步骤和蛋白质/机理返回已验证。功能表示恢复三个独立域的密度叶片，并沿用向域中心收缩 1.5 Å 的接缝处理；其余表示保持域配色与残基拾取身份。`glow.animate({morph:0.5})` 与 `morph:'auto'` 调用同一播放器；`info()` 返回构象程度和结构域转角/位移。无反应速率或 ADP 计数；纯数据催化反应包尚待单独迁移。

Electron 实测覆盖五种表示、Ap5A 开关、滑块实时更新、自动恢复连续性、种子保留、定步/跳转一致、数值校验、表示/参数/选择/镜头保存、离线重开、插件停用/重启，以及闭合结构下载失败时的静态预览与资源回滚。修复多资源旧包从无状态的外部引用读取视图状态的问题；另用截图像素检查确认选择标记跟随移动残基。设置 `GLOW_ADK_SMOKE=<目录>` 运行 `tools/studio-smoke.cjs` 复验，可用 `GLOW_ADK_CIF_DIR` 指向两个原始 RCSB 文件。

112 项 Node 测试通过，ATP、KcsA、命令/嵌入浏览器回归通过，经典构建、副本一致性和 15 个官方包校验通过。[AdK 插件说明](../plugins/adenylate-kinase/README.md)列出来源、拟合方法和兼容边界。下一项为鞭毛马达；第四阶段整体仍在进行。
