> **接下来的开发以 [HANDOFF_PLAN.md](HANDOFF_PLAN.md) 为准**（工作包、依赖、分工、验收和进度表都在那里）。本文保留为已完成工作的记录。

目标：在数据可信、可复现、性能和工程质量上向 Mol\*、NGL、ChimeraX、3Dmol.js 看齐；在**教学可见性**上保留并强化我们自己的东西：白底墨线插画风格、每个粒子都有名字、机制会动、每个画面都说清楚“哪些是测的，哪些是画的”。

相关文档：[第一轮审计](AI_AUDIT_AND_STABILIZATION.md)（不变量、分层架构、5 个冲刺）· [第二轮审计](AUDIT_ROUND2.md)（逐项核对 + 三个模拟器的差距）· [场景包格式](../../workshop/SCHEMA.md)。

## 我们和专业软件的分工

| 专业软件擅长的（要学） | 我们的特色（不能丢） |
|---|---|
| 结构数据可信：单位 Å、来源可查、分辨率和方法可见 | 一眼能看懂：团块 / 示意图 / 插画三种画法，复杂结构先简化再放大 |
| 选择语言、表示方式和组件分开（NGL / Mol\*） | 机制动画：每个粒子有名字、从体相来回到体相、计数器可读 |
| 状态树、可重放的操作（Mol\* / ChimeraX 命令） | 三层视角：细胞 → 局部系统 → 蛋白质，可以一路缩放 |
| 资源管理、性能降级、回归测试 | 证据等级徽章：实验 / 推算 / 建模 / 示意，每个场景都标 |
| 命令接口，可编程 | 创意工坊：场景包是纯数据，人和 AI 都能做、能分享 |

## 三个模拟器各自要做到什么

### 1. 细胞（整个细胞、细胞一角）
- **教学目标**：细胞有多挤、各种机器在哪、多大、多少个；从 µm 缩放到 Å 不断档。
- **要看到**：比例尺和时间尺度一直在屏幕上；分子数量来自文献浓度（标“示意”）；隔室（胞质 / 周质 / 膜）有名字；点任何一个分子能看到它是什么、来自哪个 PDB。
- **要能做**：缩放到一个机器 → 进入“局部系统”视图；暂停 / 快放；关掉某类分子看其余；计数（多少个核糖体、多少个 ATP）。

### 2. 局部系统（呼吸链、叶绿体、ATP 合酶、鞭毛马达、KcsA）
- **教学目标**：能量和物质怎么流：电子、质子、底物、产物，谁推动谁。
- **要看到**：粒子流有名字和颜色图例；能量账本（每步 ΔG、几个 H⁺ 换一个 ATP）；状态机当前阶段在 HUD 上高亮；哪些位置是实验结构、哪些是组装示意。
- **要能做**：单步执行；改条件（pH、阻断剂、底物浓度）看结果变；固定随机种子重放同一段动画；点一个蛋白进入“蛋白质”视图。

### 3. 蛋白质（任意 PDB、自动模式、拆装、构象变化、配体）
- **教学目标**：一个分子的形状、组成、活性位点、构象变化。
- **要看到**：链 / 结构域 / 序列对应关系（序列条）；配体口袋；构象变化前后两个实验结构标清楚、中间是插值；分辨率、方法、物种、文献。
- **要能做**：选择（按链、残基范围、配体周围 5 Å）；测距离；换表示方式（团块 / 卡通 / 表面 / 示意）；拆开再装回；导出图片和场景包。

## 工程不变量（每次改动都要守住）
1. `src/` 是唯一源（WP1 起）；`web/index.html` 由 `node tools/build.mjs` 生成，`desktop/app`、skill 的 `assets/viewer.html` 都是复制出来的。
2. 每个场景都过回归：`cd desktop && node scripts/regress.mjs`（6 个固定场景：4HHB、6ZPO、1K4C、4V6F 翻译、7CGO、细胞一角；检查能否载入、实体 / 链 / 残基 / 配体数量、GPU 资源、FPS，最后回到第一个场景检查泄漏）。
3. 画面里非实验的东西必须进证据徽章（`evidenceOf()`，预设和场景包可用 `evidence` 字段补充）。
4. 场景包只能是数据，永远不执行包里的代码。
5. 不删现有功能；不复制外部项目的代码（只学设计）。

## 项目结构
```
src/            查看器源码（片段 + index.html.tpl，见 src/README.md）
tools/          build.mjs（src → web）、sync-copies.mjs、check-copies.mjs
web/            构建生成的单文件查看器 index.html + 开发者页面 dev.html
desktop/        Electron 桌面版；scripts/regress.mjs 回归测试，regress/baseline.json 基线
skill/          教人 / AI 做场景的 skill（SKILL.md、references/、assets/viewer.html）
workshop/       创意工坊：official/ community/ 场景包、索引、stats.json（评分评论）、tools/ 校验与构建
docs/           路线图、审计、架构说明
.github/        CI：校验工坊、投稿机器人、讨论帖统计
```
