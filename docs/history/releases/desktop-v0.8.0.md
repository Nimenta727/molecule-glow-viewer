# 分子光影 Desktop v0.8.0 · 插件配齐、模板层与第一个平台作品

Windows 便携版（未签名，首次运行时 SmartScreen 可能提示，选择“仍要运行”）。默认仍打开经典 Viewer，「工作区」菜单可切换新版 Viewer、Studio 与经典开发者工作台。

## 相比 0.7.0 的新内容

**17 个制作插件，各自打包、各有入口、写明局限（工坊“插件区”）**
- 每个插件有自己的清单：名称、作用、增加的功能、用法、入口、依赖、权限、验证程度和**局限**。工坊新增“插件区”，可查看；其中 12 个以 `glow` 命令为入口的插件可以启用/停用（停用后命令拒绝并提示在哪里重新启用）。官方插件的代码随程序发布，开关不下载或运行任何代码；第三方代码包要等有了沙箱再开放。
- 新增 7 个 `glow` 命令：`complex`（复合体记录）、`assemble`（按共同亚基叠合并报碰撞）、`embed`（膜蛋白按疏水带朝向嵌膜并复制）、`compose`（按组成表摆放示意图）、`interactions`（成员间接触与证据等级）、`binding`（布朗动力学结合速率，对照 Smoluchowski）、`source`（受信任的外部数据源）。此前已有的 `instances`（细节分级）、`volume`、`membrane`、`benchmark`、预测结构的 `color("confidence")` 一并计入。
- 插件清单与命令、开关归属表互相核对，不会漂移（测试保证）。

**第一层：蛋白质模板（工坊“我的模板”）**
- 导入你自己的结构文件（.cif / .pdb），或输入 PDB 编号取回；**授权必须由你选择**，不清楚的文件按“仅自己使用”处理，不会放进任何发布的包。
- 从文件里读出科研基础信息（标题、实验方法、分辨率、物种、组成与链、配体、突变、文献与 DOI），文件没写的留空。
- 模板包 `.glowtpl` 可导出备份或交给别人；包里声明的来源与授权只当作对方的说法。模板库保存在本机浏览器存储里。
- Studio 里“用此模板新建作品”；Viewer 里“打开结构”。原来的“模板区”改名为“静态作品”。

**第一个用平台做的作品**：血红蛋白——四个亚基与四个血红素（静态，工坊社区区）。由 Studio 从 PDB 模板制作，每条事实可在原文件里核对。

**修正**
- **核糖体翻译里 tRNA、mRNA、新生肽链播放时消失**（视图只取最新状态、跳过了状态转换）：现在按顺序重放每个事件；打开翻译作品时自动在核糖体上剖开一个楔形口，露出里面的 tRNA。真实浏览器里确认。
- 视口统计新增每个粒子集合的实例数；GPU 验收脚本。

**检查**：测试 670 项；浏览器里确认了 ATP 合酶转子在转（计数与圈数一致）、呼吸链能量条随步骤点亮。

## 这个版本没有做到的（请如实看待）

- **真实显卡上的帧率没有测过**：开发环境是软件渲染。发布前由维护者在有独显的机器上验收（`docs/ACCEPTANCE_GPU_PROMPT.md`），数据以验收报告为准。
- 模板里读到的科研信息还没有带进用它做出的作品的资源记录；作品编号是平台生成的随机串。
- 翻译作品的动画速度快时会被压缩（一帧走完好几步），不像经典版每步完整播放。
- AlphaFold、EMDB 的地址与条款没有核对；沙箱里只验证了拒绝路径。
- 各处科学表述（结构域划分、转角数字、膜厚等）未经专业人员审阅；新平台仍为迁移预览，不代表与经典版科学或视觉完全等价，详见 docs/feature-parity.json。
