# 分子光影 Desktop v0.9.0 · 作图核心与科研分析面板

Windows 便携版（未签名，首次运行时 SmartScreen 可能提示，选择“仍要运行”）。默认仍打开经典 Viewer，「工作区」菜单可切换新版 Viewer、Studio 与经典工作台。

## 相比 0.8.0 的新内容

**Studio 像专业制作软件一样做结构作品（作图核心）**
- 版面重排：菜单栏、撤销/重做、快捷键、大纲工具栏、场景选择、一行时间线；Viewer 的前面板按“场景 / 结构 / 选择 / 动画 / 分析”分页。
- **选择驱动的表示与着色**：用选择语言（`chain A and resi 10-50`、`within 5 of ligands`）选一部分，设置它的表示（卡通 / 主链 / 团块 / **棍状（逐原子，叠在卡通上，一次最多 300 个残基）** / 隐藏）和颜色（单色，或按 B 因子、疏水性、电荷、二级结构、彩虹）。每次操作是一条规则，随作品保存，Viewer 里一样显示，可单独删除、撤销、重做。Viewer 里对应 `show(选择, 样式)` 与扩展的 `color(...)`。
- **标注与测量**：两点量距离、三点量角度、给选中的部分加文字标签，随作品保存、Viewer 里一样显示；氢键和盐桥画成按类型着色的线，指到线上看距离。
- **镜头关键帧**：在时间线上存镜头，播放（Studio 与 Viewer）时镜头在关键帧之间缓入缓出。
- **分子表面**：高斯分子表面（近似溶剂排除面），可按静电势（简化库仑）、疏水性或单色着色；作为规则保存，打开作品时重新生成。
- **一个场景可放多个结构**（最多 4 个）：“文件”菜单“把另一个结构加入当前场景…”，用来比较（例如同一蛋白的开放态和闭合态）。
- 打开文件**不会自动开启插件**：只给出提示和按钮，由你决定。

**插件面板规矩，以及五个科研分析面板（Studio “分析”页，插件共 22 个）**
- 规矩：面板只能读结构和你的选择；只能通过五扇受检查的门写回作品——外观、标注/连线、证据（只能记为“推导”或“建模”，并写明方法）、整条链的位置、自己的数据（≤ 64 KB）。出错的面板只影响自己。
- **界面接触**：两部分之间互相接触的残基；分类为氢键 / 盐桥 / 疏水接触；涂色、画线、记证据。
- **组成与性质**：残基组成、平均亲水性（GRAVY）、按个数数出的净电荷。
- **序列与二级结构**：序列、文件里登记的二级结构、螺旋/折叠段（点一下在画面里亮出）。
- **结构叠合**：按 Cα 的 Horn 拟合，叠合前后 RMSD，可移动整条链、标出偏远的残基；参考可以在同一结构里，也可以在同场景的另一个结构里。
- **分子表面与静电**：见上。
- 结果一律是“推导”证据，写明方法、阈值和限制；全部写进作品，Viewer 里能看到颜色、线、表面和移动后的位置（Viewer 里没有这些面板）。

**修正**
- 跨结构放置的坐标换算：独立重算发现第一版用错了参考中心（38.4 Å 对 1.98 Å），已修正，改后与面板一致。
- 面板在结构模型刚建好时重新挂载会冲掉已填的输入：现在保留。
- 命令名 `style` 与经典“画风”冲突，新命令叫 `show`。

**检查**：`npm test` 735 项；真实浏览器里走完整条链路的检查有：外观与导出、镜头关键帧、分析面板（接触、分类、组成、序列、表面）、同结构叠合、跨条目叠合——叠合两条都用**导出文件里的链变换和原始坐标文件独立重算** RMSD（0.607 对 0.61 Å；1.975 对 1.98 Å）；Viewer 打开保存的作品，比不带表面的同一作品恰好多出表面的三角形数。

## 这个版本没有做到的（请如实看待）

- **真实显卡上的帧率和观感没有测过**：开发环境是软件渲染。分子表面三角形很多（一条链约 8 万个），发布后请在有独显的机器上验收（`docs/ACCEPTANCE_GPU_PROMPT.md`）。
- **静电着色不是 APBS 的泊松–玻尔兹曼结果**：它是简化库仑（形式电荷加通用主链部分电荷，距离相关介电 ε = 4r，表面外 1.4 Å，单位 kcal/(mol·e)），只适合定性比较。
- **氢键、盐桥分类只用重原子距离，没有氢原子和角度判据**：阈值是常用经验值（氢键 3.5 Å、盐桥 4.0 Å、疏水 4.0 Å），不能替代 ChimeraX 等软件按原子类型加角度的做法；His、Asn/Gln 翻转没有处理。
- 表面是高斯近似，不是严格的 SES；表面是半透明叠加层，要看清请把该链样式设为“隐藏”。
- 移动过的链上，已算好的高亮、测量、标签、界面列表和表面**不会跟着走**；结构带生物组装体时（同一链名多份拷贝）不能直接移动其中一条链；后加入的结构不带外观规则、标注和表面。
- 叠合只用 Cα，不迭代剔除离群点，也不做序列比对；“核心域”的划分要由使用者决定（示例里用的 4AKE/1AKE 核心域是经验选择，未经专业审阅）。
- 这些面板和命令只在 Studio 里做；Viewer 里只能看，`glow` 命令里还没有表面、连线的对应命令。
- 模板里读到的科研信息还没有带进用它做出的作品的资源记录；AlphaFold、EMDB 的地址与条款没有核对。
- 各处科学表述（阈值、结构域划分、转角数字、膜厚等）未经专业人员审阅；新平台仍为迁移预览，不代表与经典版科学或视觉完全等价，详见 docs/feature-parity.json。
