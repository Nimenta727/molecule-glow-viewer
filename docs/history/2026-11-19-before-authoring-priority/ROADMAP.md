### 4.4 — 结构、分析与自动解释

依次接通 CCD 球棍/键级与配体来源、结合位点与相互作用/距离、口袋、域运动、拆装（配体随所属子单元移动）、全原子界面/界面印记、剖切；再补物种/方法/分辨率/文献/UniProt/GO 简介、序列与功能位点、自动定膜/朝向。任意 accession 的下载、缓存、离线/大结构诊断作为共享基础贯穿各项。

这些以可复用科研/结构工具提供；适用输入、方法、参数、单位、误差与限制明确。作者选取导入结构后运行工具，结果保存在作品或分析记录中，引用资源的确切版本；专业判断不能仅由动画外观或蛋白名称自动推断。

AdK 域角度已有特定参考对的测量，不标成通用构象域分析完成。已有 4 Å 接触列表也不标成化学相互作用、距离工具和结合口袋全部完成。

| 维度 | 证据要求 |
|---|---|
| 功能 | 同一经典用例在新版可操作，输入、选择语义、反应/过程事件和返回状态可比较；静态预览不算动态恢复 |
| 科学 | 来源/文献、物种与突变体、方程/单位、守恒/计量、数值表和容差；不同模型/时钟的原因与限制明确 |
| 确定性 | 本实现同种子重放，固定步进与 seek 一致；无随机事件者标明不适用，不制造随机性 |
| 持久化 | v2 导出重开保持坐标字节、来源、参数历史、进度、选择、镜头；已有内嵌数据不重复联网 |
| 生命周期 | 取消/快速切换/关闭/卸载释放请求、监听、动画、Worker/GPU；缺插件仍可静态查看并说明缺失能力 |
| 安全 | 包/输入不执行代码，权限拒绝有效；恶意输入和依赖版本/资源错误有负例 |
| 交互与视觉证据 | 1440 / 560 px 各截图并人工查看；最低限度控件可达。最终经典视觉等价留作单独状态 |
| 自动化与产物 | 有意义的 Node 测试与 Electron 用例，CI 对本提交运行；受影响打包产物也验证，而不是仅测试源码服务器 |

清单中的实现状态与四类验收状态独立：实现接通不自动把经典对照、科学对照、发行产物改成通过。验收结果记录提交与环境，历史日志不冒充本提交的新实测。能力确实不适用时写理由；未获维护者明确范围决定的“刻意不迁”保持待办。

## 五、提交与最终完成条件

每批只提交可复验的范围，先 fetch，再按交接执行 `pull --rebase --autostash`，审查用户改动；沿用已有作者身份，不写个人邮箱。按改动运行完整 Node、构建/副本、工坊、安全及对应 GUI/发行检查。已批准的 GitHub 同步流程继续沿用，最终发布版本与标签必须基于实际产物结果。

只有以下条件满足，才生成最终 `MIGRATION_REPORT.md` 并标记 `migration-complete`：

- 全功能清单逐项关闭，或有明确批准的范围决定与理由；不能以“经典仍可打开”代替迁移。
