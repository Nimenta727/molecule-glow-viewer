# 2026-11-21 · 4.5.0 命令接口补齐（经典 `window.glow` 兼容）

## 做了什么

新 Viewer 的 `window.glow` 之前缺经典的 `color`、`measure`、`sequence`、`clip`，`camera` 只认 position/target，`help()` 不列工具。现补齐：

- **measure**：两个选择→距离（Å），三个→角度；经由 `analysis-panel.measureNow`，与界面按钮同一条路径、同一份数值（`plugins/structure/measure.mjs`，与经典逐位一致），回包 `{kind,value,unit,points}`；`measure('clear')`。
- **sequence**：返回各链一字母序列、长度、缺失段；`{show}` 开关序列条；`{select}` 走选择语言。
- **color**：新模块 `apps/viewer-web/color-scheme.mjs`——方案 entity/chain/rainbow、单链颜色、reset；经 `buildStructureLayers` 新增的 `recolor` 回调落到每条链的图层（拾取点不变色）。**只到整条链**；按残基范围上色被明确拒绝（写明原因）。
- **clip**：`{enabled, depth, scope, aim}`，与界面共用同一份剖切状态。
- **camera**：新模块 `camera-spec.mjs`——`orbit`、`az/el/dist`、`focus`（选择处，保持视线方向），也接受 `"orbit 90"`、`"focus chain A"`；越界报错不截断。
- **animate**：接受 `"play"` / `"pause"`。
- **help()** 现在带 `tools`（`tool-help.mjs`，来自工具描述符，不含函数）和仍未迁移项的清单。
- 位置参数：`glow.measure(a,b,c)`、`glow.color('chain A','red')` 与经典相同。
- **嵌入权限**：`sequence`、`measure` 返回残基名/序列/数值，归入“敏感读取”；`color`、`clip` 是普通场景控制；授权提示文字同步。

## 验证

`npm test` 501/501（新增：color-scheme 5、camera-and-help 4、viewer-commands 6、view-layers recolor 1、权限 1）。构建/副本检查通过（classic 构建因共享的 embed-permissions.js 提示文字更新而重新生成）。

## 没做

- `style`（画风）：新 Viewer 只有一种纸墨风格，不是场景属性；命令仍被拒绝并在 help 的 limitations 里写明。
- 按残基范围上色、按选择换表示：需要逐残基着色渲染，另立项。
- 颜色状态目前不随保存包持久化（换场景即重置）；放到 4.5.2 的“工程继续编辑”里一并处理。
