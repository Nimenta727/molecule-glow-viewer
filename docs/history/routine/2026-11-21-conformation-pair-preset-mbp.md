# 2026-11-21 · 4.4.8：两态构象工具的预设机制，麦芽糖结合蛋白作为第二个“作品”

## 做了什么

1. **发现**：AdK 的播放器（`org.glow.tool.conformation-pair`，旧 id 为 AdK 专用播放器）几乎全是配置驱动——链、结构域、两个状态的编号、参考配体、名称匹配都在数据里。所以“升成通用工具”的实际做法不是重写，而是让别的蛋白能**只靠数据**用它。
2. **预设机制**：工具描述符的 `author.presets: [{ id, label, config }]`。每个预设在工具注册时就要通过该工具自己的校验器（写错的预设让插件无法启用，而不是等人选到时才出错）。Studio“添加工具”下拉里，同一个工具的默认模板与各预设并列。
3. **麦芽糖结合蛋白预设**（`plugins/adenylate-kinase/templates.mjs`）：1OMP（开）/ 1ANF（闭），A 链 370 残基；N 域（1-109、264-309）为参考域，C 域（114-259、317-370）与铰链（110-113、260-263、310-316）相对它测量；参考配体为 1ANF 链 B 的 GLC（麦芽糖，23 个原子）。三个域覆盖 1–370 每个残基各一次（有测试）。
4. **交叉验证**：AdK 自带的结构构建器只给 MBP 配置，与我之前独立写的通用 `state-pair` 算出的数字逐位相同：RMSD 0.7212 Å、C 域 36.21° / 10.21 Å、铰链 17.41°。`tools/second-pair-check.mjs` 9/9，报告 `docs/parity/second-pair-mbp-report.txt`。
5. **端到端（真实浏览器）**：`tools/mbp-work-check.cjs`——Studio 导入 1OMP、选预设添加工具（适用性检查通过）、导出场景包；全新 Viewer 启用结构插件后打开该包，机制面板出现，闭合到 1 时度量与上面一致；播放时间前进；无脚本错误。截图 `docs/images/mbp-work-opened.png`。
6. **顺手修的真问题**：机制面板的标题与证据文字原来取自插件注册时固定的 AdK 面板，所以 MBP 作品会显示“AdK 腺苷酸激酶”。现在播放器带着作品配置里的 `panel`，Viewer 优先用它（ATP 合酶同样改了）。参数标签“显示闭合态 Ap5A 参考”改为“参考配体”（科学卡同步）。
7. 测试 557 项；对照基线只因三个源文件哈希变化而重新生成（数值不变）。

## 如实说明

- 域的边界来自我对该蛋白文献的记忆，没有逐条核对原文，**需专业人员确认**；度量是两套沉积坐标的几何量，画面是线性插值（示意），不是真实路径。
- 这个工具仍是 player-v1（有自己的时钟），没有变成 layer-v1；ATP 合酶的播放器几何仍围绕 c 环与三个 β 亚基，没有做同类通用化。
- “蛋白”仍靠名称模式匹配链（`namePattern`），Studio 里还不能直接编辑结构域残基范围（只能选预设）。

## 下一步

- 回退/干预界面和能量条的肉眼确认；整细胞区域层级。
