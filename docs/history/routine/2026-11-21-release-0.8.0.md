## 过程中发现并修好的问题

- **Studio 的真 bug**（Windows 门禁抓到）：新加对象后，旧的选中行还留在选择集合里，“删除”会删掉旧对象而不是新加的。是此前做大纲多选时引入的。修复：`reconcileSelection`（保证“检查器显示的对象”一定在选中集合里）+ 单测。
- **工坊工作流本来就坏**：三个工坊工作流缺 `npm ci`，在 main 上已连续失败（运行 61–65）。已补。
- **我说错的一句话**：我先说“这个容器装不了 Electron”，其实只是没有真去试下载；后来下载成功，才能在本地复现并验证 Studio 的失败。已在 PR 描述里更正。
- 工坊工作流在合并后又自动提交了 `workshop: rebuild index / stats`（`workshop/stats.json`），属于它的正常行为。
