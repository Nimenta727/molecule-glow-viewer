# 2026-11-21 · D1 相互作用证据层

## 做了什么

`plugins/structure/interaction-evidence.mjs`（纯逻辑）：
- `interfaceBetween`：两组链（各自可带放置变换）之间的界面——重原子之间距离不超过截止值（默认 4.5 Å）的原子对数、最近距离、两侧的界面残基（“链:编号 残基名”）；
- `pairEvidence`：一对摆放的**证据等级**，取较弱的一方：`experimental`（两边都是同一个条目里测得的坐标）→ `derived`（至少一边是叠合推导的）→ `predicted`（涉及预测结构资源）→ `modelled` → `illustrative`；附原因（“‘X’的位置是推导的：叠合……RMSD……”）；
- `interactionsOfComplex`：对复合体记录（A3）里所有成员的所有副本两两算界面，达到最少接触数（默认 10 对原子，几个偶然靠近的原子不算界面）才列出；按证据强弱、再按接触数排序；缺模型的成员单独报告，不静默丢；`degrees` 数每个副本有几个伙伴。

接触是**放置后坐标的几何事实**，不代表亲和力，也不代表这个相互作用在细胞里真的发生；证据等级回答的是“这个相对位置从哪来”。

## 验证

- 单测 4 项：界面的原子对与残基、截止值、变换后的界面（把远处的链移过来就成为界面）；证据取较弱一方并带原因（experimental → derived → illustrative，预测结构单独成级）；复合体的相互作用只含接触的对、缺模型会说、`maxPairs` 保护；
- 真实数据 `node tools/interaction-check.mjs <结构目录>`（报告 `docs/parity/interaction-6n2y-report.txt`）：**枯草芽孢杆菌 PS3 ATP 合酶（6N2Y）**。期望完全来自这个酶的已知结构，不是来自程序打印的数字：F1 头部三个 α、三个 β 交替围成一圈，所以每个 β 恰好接触 2 个 α、每个 α 恰好接触 2 个 β，α 之间、β 之间不接触；c 亚基成十个的环，每个恰好接触 2 个 c。从坐标算出：**每个 β 接触 2 个 α，每个 α 接触 2 个 β，同种不接触；10 个 c 每个恰好 2 个 c 邻居**（共 10 对 c–c）；γ 轴与 3 个 α、3 个 β 接触；最大的界面是 α(B)–β(F)：598 对原子、55 + 51 个界面残基；22 条蛋白链共 41 对相互作用，证据全是 experimental（同一个条目）。

## 如实说明

- **没有 Viewer/Studio 界面**：现在是函数和命令行检查，还不能在画面上点一个蛋白看到伙伴和证据；
- **没有接外部相互作用数据库**（IntAct、STRING 等）；“database”这一类证据没有实现，因为那需要 A4 的数据源客户端和授权核对；
- 接触只看重原子距离，不区分氢键、盐桥、疏水接触，不算埋藏表面积；
- 同一个条目里的相互作用被标成 `experimental` 是指**位置**是测得的，不是说这个相互作用经过了单独的实验验证（例如晶体里的接触可能是堆积产生的）；
- 所有成员对都检查，N 个副本是 O(N²) 对（有 `maxPairs` 保护），数千个副本的细胞器级场景需要空间索引，这里没做。
