# 2026-11-20 Studio 粒子预览

## 做了什么
作者在 Studio 里配置“溶液粒子与流”和“数据反应动画”时，可以直接看到粒子：工具页签里出现“预览粒子”勾选框（场景里有这两种工具才出现）。
- `apps/studio-web/particle-preview.mjs`：用 Viewer 同一套引擎（`Solution`、`DataAnimation`、取向适配器）在作品的主结构上运行，通过视口的粒子层画出；每个粒子都有名称；配置被编辑后（工具面板改字段→场景刷新）下一次同步会重建预览；视口重建后自动重画；结构还在解析时给出说明；没有可预览的工具时说明并关闭。预览**不改作品**（播放和保存仍在 Viewer）。
- 测试：`apps/studio-web/test/particle-preview.test.mjs`（3 项：溶液粒子出现且会动、数据动画与改配置重建、无工具/无结构的提示）；测试运行器加入 `apps/studio-web/test`；`npm test` 416。
- 浏览器实测：Studio 导入 4AKE，添加“溶液粒子与流”，勾选预览：H⁺ 带名称标签的黄色粒子在结构周围游动。截图 `docs/images/studio-particle-preview.png`。

## 限制
- 粒子画在结构自己的位置：在 Studio 里移动/旋转了对象，粒子不会跟着走（面板里写明）。
- 只预览这两个工具；随机过程、翻译、多过程是面板和曲线，没有三维粒子，所以不在预览里。
