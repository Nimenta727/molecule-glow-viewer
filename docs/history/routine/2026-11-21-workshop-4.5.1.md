# 2026-11-21 · 4.5.1 工坊：详情、版本、授权、派生与依赖诊断

## 做了什么

工坊原有分区、检索、主题/来源/标签过滤、资源依赖展示、哈希核对；缺的是每个条目的**详情**、**版本**、**署名与授权条款**、**派生关系**和**依赖诊断**。现补齐：

- **`plugins/workshop/diagnose.mjs`**（纯函数，对话框与校验器共用，所见即 CI 所验）：
  - 授权条款表与 `derivativeLicenses`：来源含 CC BY-SA → 派生只能 CC BY-SA；CC BY → BY 或 BY-SA；CC0 → 三种皆可；来源授权不认识 → 不承诺并说明原因。
  - `checkDerivation`：来源必须存在、`revision` 不能超过现有版本、不能自己派生、授权必须兼容、派生链不能循环。
  - `describeEntry`：作者（只提供 https 链接）、版本/更新日期、授权条款、派生链（向上与向下）、所需工具（按名称）、结构与资源；资源条目给来源、哈希、可否嵌入、被哪些作品使用。
  - `diagnose`：**错误**（需要的工具本应用没有；派生来源已不在目录；资源为 CC BY-SA 而作品授权不是 BY-SA）、**注意**（资源不在目录、结构未登记为资源、资源禁止嵌入、授权不认识）、**说明**（须署名、仅引用、来源已更新）。
- **目录条目**（`catalog.mjs`）新增 `revision`、`author`、`derivedFrom`。
- **对话框**：每张卡片加“详情/收起详情”，展开显示上述信息和依赖诊断；有会妨碍打开的错误时卡片上直接标红提示。工具是否可用由应用传入 `toolAvailable`（`isKnownTool`，Viewer 与 Studio 都接上）。
- **作品包 `derivedFrom: { id, revision? }`**：`glow-lib.checkFile` 校验形状，`validate.mjs`/`build-index.mjs` 另做全目录检查（`derivationProblems`），索引写入 `derivedFrom`；`workshop/SCHEMA.md` 说明规则。
- 浏览器实测：`tools/workshop-shot.cjs`（Playwright 用请求拦截提供仓库文件，不起服务进程，Three.js 用 `desktop/vendor/three` 代替 CDN）在真实 Chromium 里打开 Viewer 的工坊、展开作品与资源详情；截图 `docs/images/workshop-details.png`、`workshop-details-narrow.png`（390 px 宽），页面无脚本错误。
