# 2026-11-20 4.4.8 转子联动（ATP 合酶、鞭毛马达）

## 做了什么
经典里质子和转子角度绑在一起：鞭毛马达每转 1/44 圈过一个质子，ATP 合酶每转 1/8 圈回流一个 H⁺、每转 1/3 圈出一个 ATP。新版此前只有"固定速率的流 + 另一个独立的部件自转开关"。现在**转子由数据动画引擎持有**，部件自转与质子事件同出于一个角度。

## 设计
- 角度＝引擎时钟的确定性函数（速度 × 动力学通量 × 快慢 × dt 的累计），因此回退/重放得到同样的角度，快慢/时间尺度不改变角度的计算。
- 流写 `perTurn: n`（`phase` 以圈计）：转子每跨过 1/n 圈发出一次，不再按速率；快速时间尺度下不画粒子、计数器按同样的圈数增长。
- `rotor.stock`：计数器（如"H⁺ 膜间隙存量"）小于 1 时转子停下，经典的 `rotorRate`（存量用完转子停）；`rotor.by` 让速度跟动力学模型的通量走。
- `derived`：由其它计数器算出的计数器（存量＝泵出＋释放－回流；ATP＝回流×3/8；ATP/NADH），与经典的账本口径相同。

## 改动
- `data-spec.mjs`：`rotor`、流的 `perTurn`/`phase`、`derived`（校验与限额）。`data-animation.mjs`：`#turnRotor`、`#derive`；`summary()` 带 `rotor`；`perTurn` 流不进速率计时器、不进快速流层，也不被"按速率计数"重复计入。
- `works/respiratory-relay.mjs`：ATP 合酶的 a 亚基质子通路锚点（膜上 −34/−6/+6/+34 Å）、F1 头部出口、`H⁺ 经 ATP 合酶回流`（每转 8 个）与 `ATP 离开 F1`（每转 3 个）两条流、账本、`respiratoryRotor`（场景 `spin` 列出的 γ 柄与 c 环，0.25 圈/秒满通量）。`works/mechanism-works.mjs`：呼吸链带上述内容；鞭毛马达改为 11 个定子各每转 4 个质子、相位差 1/44 圈，转子是场景 `spin` 里的部件（0.1 圈/秒，长轴）。
- Viewer：`object-spin.mjs` 新增 `drive({parts, mode, angle})`（按部件名找部件、求轴，角度由动画给；读者自己的勾选被替换，驱动态不写进工程）；`data-animation.mjs` 每步把引擎的转子角度交给它；停止/重置时放手。
- 文档：`tools.md`、`feature-parity.json`。

## 验证
- `npm test` 446/446。新增 `rotor.test.mjs`（5 个）：声明校验；鞭毛：整一圈恰好 44 个质子、转子不受时间尺度影响、慢速下质子真的穿过、账本平衡；呼吸链：每转 8 个 H⁺、ATP＝回流×3/8、存量等式、存量不低于一步的 1 个质子；没有底物转子停下；回退重放角度完全一致。
- 6ZPO 真实结构上锚点的部件名命中：a 亚基 226 个残基、β 1403、γ 272、c1 597。`relay-parity` 26/26（5GUP 与 6ZPO）。

## 没有做 / 限制
- **转子的轴是 `sym`/`long` 的自动求法，没有在浏览器里看**：ATP 合酶 γ+c 环的对称轴、鞭毛转子的长轴是否与经典所见一致未肉眼确认。
- 转子速度是固定值（经典是滑块），ATP 合酶的流和 ATP 事件位置用 a 亚基/β 亚基的部件中心加偏移，不是经典里逐个 c 亚基的位置。
- 鞭毛转向（CheY-P）仍未做。
