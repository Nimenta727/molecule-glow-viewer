# 2026-11-21 · 4.3 基座收尾（第一批）

## 做了什么

1. **工具描述符新增 `outputs` 与 `dependencies`**（`packages/plugin-host/tool-descriptor.mjs`）：`outputs` 声明工具产出什么（计数/曲线/状态/事件/文件，含单位），`dependencies` 声明依赖的插件及精确版本；校验规则：键唯一、种类固定、版本须为 x.y.z。8 个内置工具（ATP 合酶、AdK、KcsA、溶液粒子、数据动画、随机过程、翻译、多过程）都已填写；`glow.help()` 现在会列出它们。
2. **导出授权过滤（纯逻辑）**（`packages/schema/export-policy.mjs`）：`planEmbedding(scene, resources, { mode })`。`project`（默认）原样保留；`publish`：资源记录 `embedAllowed:false` 且有公开来源时，该文件资产改成带资源 id/版本/哈希的 `external` 引用并去掉字节；没有可取回来源的本地文件则列入 `blocked`，字节不会被悄悄丢掉。
3. 测试 542/542（新增 5 项）；对照基线只更新了三个工具文件的哈希（数值不变，实结构行 5 条仍在）。

## 第二批补充

4. **取回引用**：`hydrateReferences`（同文件）——打开带 `external` 资源引用的包时，用注入的取回函数拿字节，SHA-256 与资源记录一致才接受，并还原为普通文件资产；失败（离线/哈希不符/无记录）保留引用并给诊断，不拒绝场景。Viewer 载入路径已接入（仅 RCSB 来源）。
5. **Studio“导出发布包”按钮**：保存发布信息 → 按 `publish` 模式规划 → 对结果做发布检查 → 有错误就不生成包并写明原因；无错误则下载。本地文件（来源 `local file`）视为无来源，拒绝。
6. 修了一个我自己的疏漏：本地导入的来源写作 `local file`，一度会被当成可取回的引用；现在只有 RCSB 才允许变引用（有测试）。
7. 检查脚本：`tools/*.cjs` 找不到打包出的 `desktop/vendor/three` 时回退到 `desktop/node_modules/three`（在未打包的开发环境里也能跑）；新增 `tools/studio-export-check.cjs`。测试 547 项。

## 如实说明
