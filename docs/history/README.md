# 历史文档

这里保存项目早期的审计、路线图、平台规范和交接文档。它们用于追踪设计决策、历史问题和已完成工作的背景。

当前开发以 [`../DEVELOPMENT_FRAMEWORK.md`](../DEVELOPMENT_FRAMEWORK.md) 为总纲；历史文档中的任务清单、代码行号和状态可能已经过时，使用前应与当前源码核对。

| 文档 | 用途 |
|---|---|
| `AI_AUDIT_AND_STABILIZATION.md` | 第一轮审计、工程不变量、AI 修改协议 |
| `AUDIT_ROUND2.md` | 严格审计、缺陷分级、开发者 API 和回归要求 |
| `PLATFORM_AUDIT_REPORT.md` | 产品定位、平台分层和专业软件借鉴边界 |
| `PLATFORM_ENGINEERING_SPEC.md` | 目标架构、数据模型、生命周期、性能和实施批次 |
| `HANDOFF_PLAN.md` | 原始工作包、依赖、分工和验收清单 |
| `HANDOFF_CORE_PLUGINS.md` | 主体、制作区、插件和光影包规划 |
| `ROADMAP.md` | 阶段性完成记录和旧路线图 |
