# 四种展示模式 M3

在 Studio 的场景树创建或导入对象。用属性面板的「父对象」建立层级，在「视角书签」保存想用于 Viewer 的镜头。已有工程也可直接添加展示视图。

1. 展开「四模式导航」，创建细胞入口。选好目标对象、镜头和可见标注后，点「保存视图」。
2. 新增局部系统和蛋白质视图。在「进入来源」选择上一级视图，按需指定热点。在局部系统视图中可添加示意方向。
3. 新增反应机理视图，可同时选择局部系统和蛋白质作为进入来源。为每一步填写名称和参与对象。需要同步播放时，先为动画对象添加关键帧，再勾选「与时间线同步」，使用播放位置或输入时间为步骤定位。
4. 保存并重开工程后，可继续编辑视图。用「导出场景」生成 `.glow v2`，再在 Viewer 中打开并浏览。

视图编辑会进入撤销和重做历史。添加节点、关键帧、标注或书签时保留当前视图草稿。保存工程、导出、切换场景及撤销重做前需要先保存或放弃当前草稿。删除仍被视图引用的对象时会显示对象和视图名称。
