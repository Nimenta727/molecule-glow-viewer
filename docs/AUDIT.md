# 项目审计（2026-11-24，Desktop 0.13.0 发布前）

本页是对整个项目的一次全面审计：代码、测试、安全、性能、科学可信度、界面可用性、文档与发布流程。结论都附证据（文件、检查脚本或数字）；做不到的检查写明“没有做”。上一版审计见 [history/AUDIT_2026-11-22.md](history/AUDIT_2026-11-22.md)。这不是第三方安全审计，也不是专业科学审阅。

## 一句话

功能面已经很宽（经典 Viewer、新 Viewer、Studio、26 个插件、工坊、AI 命令接口），单元测试扎实（756 项全过），但**有三类系统性风险**：① 桌面版的 Electron 版本已过支持期，页面没有内容安全策略；② 29 个真实浏览器检查脚本都不在 CI 里，回归要靠人工跑（这次就有“大模板打不开”在发版前才被发现）；③ 所有视觉效果和大结构性能**只在软件渲染下验证过**，从未在真实显卡和真实 Windows 上验收。

## 发现（按严重程度）

| # | 严重 | 发现 | 证据 | 建议 |
|---|---|---|---|---|
| 1 | 高 | **Electron 33.4.11 已过支持期**：Electron 只维护最新三个大版本，33 早已停止安全更新，内置的 Chromium 有已知漏洞不会再修 | `desktop/node_modules/electron/package.json`；`desktop/package.json` 写的是 `^33.2.0` | 升级到当前受支持的大版本，跑一遍 `platform.yml` 的暂存/EXE 回归和安全冒烟 |
| 2 | 高（已修） | **经典 Viewer 会把场景文件里的说明文字和部件讲解当 HTML 插入页面**：一个恶意的 .glow（社区或本地文件）可以往页面里注入标签和脚本 | `src/core/load-scene.js` 的 caption、`src/derived/selection.js` 的 notes；现有内容都不含 HTML | 已改为转义（提交 462bebc），`web/index.html` 已重建、副本已同步。其余 `innerHTML` 处都经过转义 |
| 3 | 中 | **页面没有内容安全策略（CSP）**，桌面版对非缓存主机的 https 请求一律放行（`passThrough`） | `desktop/main.js` 的 `handleHttps`；各 `index.html` 无 CSP | 加 CSP（只许本地脚本和白名单主机）；`handleHttps` 改成白名单。沙箱、上下文隔离、导航白名单已在（`webPreferences`、`network-policy.cjs`） |

| 7 | 中 | **两套实现并存**：经典 Viewer（`src/` 单文件，约 8100 行）是桌面版默认入口，新 Viewer/Studio 的新功能（查看页、三维卡通、相互作用、光影包、本地作品）经典版都没有 | `desktop/platform-shell.cjs` 的入口表 | 决定默认入口；用户多次反馈“功能找不到”，部分原因是打开的是经典版 |

## 界面：按钮巡检

`tools/button-sweep-check.cjs` 在 Viewer（打开 2HHB）和 Studio（导入 2HHB）里把每个可见按钮逐个点一遍，记录报错和“点了没有任何可见变化”的按钮。结果与处理见本页末尾“按钮巡检结果”。

## 做得好的地方（有证据）

- **单元测试**：149 个测试文件、756 项全过；对几何（三维卡通、虚线管）、插件清单、工坊目录、本地作品库、命令参数都有覆盖。
- **依赖极少**：运行时只有 `@cfworker/json-schema`、`@zip.js/zip.js` 和 `three`（锁定版本）；没有第三方 UI 框架。
- **桌面版隔离**：`contextIsolation: true`、`nodeIntegration: false`、`sandbox: true`；导航只允许应用自己的页面，外链交给系统浏览器；`app://` 协议拒绝越界路径。
- **发布可追溯**：发布工作流先过闸门（暂存与真实 EXE 回归、安全冒烟、数值对照），清单记录源码提交与逐文件 sha256。
- **如实标注**：每个分析回包带 `limits`，插件清单写 `status.limits`，发行说明有“没有做到的”。

## 没有做的检查

- 没有运行依赖漏洞扫描（`npm audit` 需要联网到 npm 漏洞库，这次没跑）。
- 没有在 Windows、真实显卡、macOS 上运行。
- 没有对插件做沙箱隔离（官方插件与应用同源运行；社区插件目前不执行代码）。

## 按钮巡检结果

`tools/button-sweep-check.cjs` 在 Viewer（打开 2HHB）和 Studio（导入 2HHB）里点了 84 个可见按钮（Viewer“查看”页的 40 多个按钮另由 `tools/viewer-view-panel-check.cjs` 逐个点过：显示方式、颜色、作用力、表面、光影、周边残基、组成、界面、标签、剖开、视角，全部有效，选中状态正确）。
