# 分子光影 Desktop v0.13.0 · 真正的三维卡通、价键与相互作用、重做的光影包、完整的 T7 噬菌体

Windows 便携版（未签名，首次运行时 SmartScreen 可能提示，选择“仍要运行”）。默认仍打开经典 Viewer，「工作区」菜单可切换新版 Viewer、Studio 与经典工作台。

## 相比 0.12.0 的新内容

**四种显示方式都是真正的三维几何**
- **卡通**：沿平滑曲线，螺旋是宽带、折叠是带箭头的片、卷曲是圆管；**主链**：平滑圆管；**团块**：不变；**价键**：每根键是有明暗的圆柱、按元素着色，**整条蛋白都能画**（一次最多 3 万个残基；球棍 6000 个）。此前卡通和主链是细线和平面条带。
- 每个官方蛋白质模板都能显示这四种方式（发布前逐个检查）；模板默认仍是残基样式。
- 大复合体自动用较粗的扫掠，整颗病毒用粗圆管，让每个部件成为颜色清楚的实体。

**相互作用力**
- “查看”页“氢键 / 盐桥 / 疏水作用 / 全部作用力”：画成虚线圆管，连在两端原子之间，会被前面的结构挡住（不再浮在画面最上层）；两端的残基自动显示为价键。氢键蓝、盐桥粉、疏水绿。

**光影包重做**（每种显示方式在每个包里都截图调过）
- **论文白底·描边**：墨线描边、体积明暗、分子边缘向白底淡出的浅灰投影。
- 三个暗色包：深色描边、分子边缘向背景扩散的彩色光晕；轮廓光调弱，细的主链和卡通不再发虚。

**界面**
- 选中的选项（显示方式、颜色、表面、作用力、光影、鼠标模式、只看某条链）保持高亮。

**噬菌体 T7 完整模型（发行页另附作品文件）**
- 一个整体：二十面体头部（415 个 gp10A，分成 60 个六聚体、11 个五聚体）、门户-尾部、6 根完整尾丝、内部核心、盘绕的基因组 DNA；在 Viewer 里用“拆装”可以把 203 块逐块拆开、放回。
- 来源：Guo 等 PNAS 2014（3J7X）；J. Virol. 2025（9JYZ、9JYY）；Cuervo 等 Nat. Commun. 2019；Garcia-Doval 与 van Raaij PNAS 2012（4A0T，尾丝末端）。

**修复**
- 大模板（20S 蛋白酶体、核糖体、鞭毛马达等）在新几何下会因“预览超过场景包容量”打不开：场景包里改存轻量预览，屏幕上实时画三维。
- 几十万个残基的结构在拆装、镜头对准、B 因子着色时会“调用栈溢出”：已改。

## 这个版本没有做到的（请如实看待）

- **T7 模型里的示意部分**：三部分之间的相对位置、DNA 的缠绕方式、尾丝中段（第 144–370 号残基，没有任何实验或预测结构，画成三股示意链，浅粉色）和尾丝末端的朝向是作图时的假设；衣壳只有 Cα，不能显示价键；DNA 只有磷酸骨架，没有序列。
- T7 作品包约 120 MB，接近 128 MB 的场景包上限；整颗病毒在软件渲染下打开约 45 秒，**真实显卡上没有测过**。
- 价键的球径和键粗是绘图尺寸，不是范德华半径；相互作用只用重原子距离，没有角度判据，是筛查不是结论。
- 0.9.0 以来列出的其他限制仍然成立：静电是简化库仑、叠合只用 Cα、表面是高斯近似、各处科学表述未经专业人员审阅。
- T4 噬菌体还没有做（下一步）。
