# 分子光影 Desktop v0.11.0 · 能点的“查看”页、视角控制、球棍与光影包插件

Windows 便携版（未签名，首次运行时 SmartScreen 可能提示，选择“仍要运行”）。默认仍打开经典 Viewer，「工作区」菜单可切换新版 Viewer、Studio 与经典工作台。发行页只放软件本体、插件、基础蛋白质模型（随软件）和光影包插件；**作品不在这里发布**。

## 相比 0.10.0 的新内容

**新 Viewer：功能终于有按钮了**
- **“查看”页**：选作用对象（全部 / 小分子 / 某条链 / 自己写选择）后，点按钮即可改显示方式（卡通、主链、团块、棍状、**球棍**、隐藏）、颜色（按链、彩虹、二级结构、疏水性、电荷、B 因子、自选色）、分子表面（单色 / 疏水 / 简化静电）、光影、沿视线剖开；**亚基列表**可显示/隐藏、选中、聚焦、“只看它”；“拆装”（把亚基取下来）也在这一页。
- **“视角”页**：鼠标左键可设为旋转 / 平移 / 缩放；旋转、平移、缩放按钮；正/背/左/右/上/下视角；“以所选为中心并拉近”；滚轮朝鼠标所指处缩放；**双击画面上的点把它设为旋转中心**。
- 想看分子要先在“结构”页勾选“启用官方结构插件”，“查看”页上有这句提示。
- 按钮、芯片、图例的文字改为自动换行，不再被省略号截断；面板加宽。

**插件（共 24 个）**
- **光影包**成为可拆卸的插件（工坊“插件区”可停用）：暗场·细胞内部、冷光·膜蛋白、暖光·活性位点、论文白底。
- 新增 **周边残基查看**：选一处，把周围一定距离内的残基画成棍状/球棍并给出分类个数。
- **组成与性质分析**、**界面接触分析**：原来只在 Studio 里，现在 Viewer 的“查看”页也能看（只读）。
- Viewer 新增命令：`surface`、`lookPack`、`composition`、`contacts`、`neighborhood`；`show` 增加 `ballstick`。

**修复**
- 个别 Windows 机器上所有在线结构“载入失败：Failed to fetch”的原因已在 0.10.0 修复（结构缓存提交遇到 `EXDEV` 时改为复制再删除）；本版延续。
- 棍状的元素颜色此前被当成未知颜色，已修。

## 这个版本没有做到的（请如实看待）

- 球棍的“棍”是细线，不是圆柱；球径固定 0.4 Å，不是范德华半径；一次最多 300 个残基（选“全部”会被拒绝并说明）。
- 新增的按钮和视角控制只在软件渲染的浏览器里点过，**没有在真实 Windows 和真实显卡上验收**。
- Studio 里还没有这些按钮型入口（Studio 主要供 AI 命令和专业制作者）。
- 界面接触只用重原子距离、无氢原子与角度；组成与性质的净电荷按个数数，不含 pKa；周边残基只是几何上的“附近”，不代表相互作用。
- 0.9.0 / 0.10.0 里列出的限制仍然成立：静电是简化库仑、叠合只用 Cα、表面是高斯近似、各处科学表述未经专业人员审阅。
