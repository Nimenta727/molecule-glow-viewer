# 分子光影 Desktop v0.12.0 · 原子细节（球棍、价键、氢键）与文字标签

Windows 便携版（未签名，首次运行时 SmartScreen 可能提示，选择“仍要运行”）。默认仍打开经典 Viewer，「工作区」菜单可切换新版 Viewer、Studio 与经典工作台。发行页只放软件本体、插件、基础蛋白质模型（随软件）和光影包插件；**作品不在这里发布**。

## 相比 0.11.0 的新内容

**新 Viewer “查看”页：原子细节**
- **球棍模型**（原子球＋键线）、**价键模型**（按共价距离连的键，按元素着色）、**画氢键和盐桥线**、清除键线。模板（静态作品）打开后默认仍是残基样式，这些细节由使用者按需打开。
- 新插件 **氢键与价键细节**（命令 `glow.hbonds`）：一部分内部的氢键（重原子距离 2.4–3.5 Å）和盐桥（≤ 4.0 Å）画成蓝/粉的线，最多 200 条，随作品保存。
- 新插件 **文字标签**（命令 `glow.label`）：给选中的一处写文字标签，画在它的中心，随作品保存，与 Studio 的标签是同一份数据。
- 插件共 26 个，都可以在工坊“插件区”单独停用。

**修复**
- 同一部分内部的氢键以前会得到 0 条（共有的残基被跳过）：`interactionsBetween` 新增 `within` 模式，每对原子只算一次。

**作品的本地导出与导入**
- Viewer 的“打开”、Studio 的“导入场景包…”可以打开 .glow 作品；Studio 的“导出场景”写出 .glow。用噬菌体的四个作品核对过（4–113 MB）：重新导出后字节数与原文件完全一致。

## 这个版本没有做到的（请如实看待）

- 球棍和价键一次最多画 300 个残基（选“全部”会被拒绝并说明）；“棍”是细线，不是圆柱；球径固定 0.4 Å，不是范德华半径。
- 氢键只用重原子距离，没有氢原子和角度判据，是筛查不是结论；Asn/Gln 酰胺和 His 环的翻转没有处理。
- 标签不避让别的标签，密集处会叠在一起。
- 新增的按钮只在软件渲染的浏览器里点过，**没有在真实 Windows 和真实显卡上验收**；最大的作品约 3000 万个三角形，需要像样的显卡。
- Studio 里还没有这些按钮型入口。
- 0.9.0 – 0.11.0 里列出的限制仍然成立：静电是简化库仑、叠合只用 Cα、表面是高斯近似、各处科学表述未经专业人员审阅。
