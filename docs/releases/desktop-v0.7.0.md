# 分子光影 Desktop v0.7.0 · 作者全流程与工坊闭环

Windows 便携版（未签名，首次运行时 SmartScreen 可能提示，选择“仍要运行”）。默认仍打开经典 Viewer，「工作区」菜单可切换新版 Viewer、Studio 与经典开发者工作台。

## 相比 0.6.0 的新内容

**作者与发布（4.5）**
- **Studio“发布”标签**：填写作者、授权（CC0 / CC BY / CC BY-SA）、主题、简介、标签、版本、更新日期和“派生自”；发布检查给出问题 / 注意 / 说明（编号被占用、新版没升版本、放宽 CC BY-SA、派生授权不兼容、缺少工具、资源不许嵌入……）。工坊校验脚本跑同一套规则，并同时收经典 v1 包和 Studio 导出的 v2/v3 场景包。
- **草稿恢复**：编辑时自动在本地留草稿，意外关闭后下次打开 Studio 提示“恢复草稿 / 丢弃”。
- **工坊详情**：每个条目可展开看作者、版本、授权条款、派生链、所需工具和依赖诊断。
- **缺少工具/插件的作品照常打开**，原因写进场景诊断；旧工具编号按现行编号运行。

**命令接口（4.5.0）**：新 Viewer 的 `window.glow` 补上 `measure`、`sequence`、按整条链的 `color`（随保存包保存）、`clip`，以及 `camera` 的旋转 / 角度 / 聚焦写法；`help()` 列出已注册的工具及其参数。

**作品（4.4.8）**
- 鞭毛马达：新增驱动梯度滑块与 CheY-P 换向开关。
- 细胞一角：通道按经典规则摆在核糖体切面内、膜下方（纯逻辑与经典在真实 4V6F + 1K4C 上 8/8 一致）。
- ATP 合酶的事件时间表与经典对照（6/6）；KcsA 增加胞外 Na⁺ 控件。
- 修正：转子完全没动时不再放过质子。

**检查**：重复加载稳定性（真实浏览器里反复载入结构，GPU 对象数不增长）、工坊详情与 Studio 发布/恢复的真实浏览器检查；测试 537 项。

## 资产

- `MoleculeGlow-0.7.0-win-x64.exe`：便携 EXE
- `molecule-glow-viewer-skill-0.7.0.zip`：制作 Skill（含“从制作到发布”六步）
- `desktop-validation-0.7.0.zip`：暂存与实际 EXE 回归的日志、截图和 JSON
- `release-manifest.json`、`SHA256SUMS.txt`：源码提交、内容哈希与逐文件校验

所有资产由 `desktop-release` 工作流在标签提交上构建，且完整发布闸门全部通过后才上传。新平台仍为迁移预览，不代表与经典版科学或视觉完全等价，详见 docs/feature-parity.json；真实 GPU 上的性能与外观尚未验证。
