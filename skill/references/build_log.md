# 制作记录：这个查看器是怎么做出来的

按真实顺序记录：需求怎么定的、为什么选这个技术、每一轮调试看到了什么、怎么改的。

## 0. 需求演变（为什么是现在这样）
1. 最初用 Blender + Molecular Nodes 做“细胞内部拥挤场景”，每个原子一个球，Cycles 渲染出图。
2. 用户反馈：**原子太细节、不好用**；给出参考图（B 站鞭毛马达动画截图：黑背景、饱和配色、团块 + 发光、剖开的膜）。
3. 用户明确：**不要 Blender（那是做视频的）**，要能**实时、任意角度看**，效果要**精致、尽量像参考图**；**所有结构都要能看**，直接从 RCSB 下载；带轻微运动（转子转）。
4. 选型讨论：Three.js 自写网页（可完全控制风格，零安装）> Mol*（无辉光、风格受限）> ChimeraX（科研风）> Unity（太重）。选 Three.js。

## 1. 数据获取（先验证接口再写代码）
- 用 curl 带 `Origin` 头测试：`models.rcsb.org` ModelServer 返回 `access-control-allow-origin: *` → 浏览器可直接请求。
- 只取 Cα：7CGO 只有 4 MB（完整 mmCIF 约 40 MB）→ 决定“每个残基一个团块”，同时天然得到参考图的粗粒化外观。
- 核酸没有 Cα → 另取 P 原子。
- 名称、组装体：GraphQL 一次查询拿到实体描述、asym_ids、组装体算符；同样允许跨域。
- 组装体算符表达式解析（`(1-60)(61-88)` 笛卡尔积）自己实现。

## 2. 鞭毛马达的组成（RCSB 搜索 + 逐个确认）
- 搜索 “flagellar motor / C-ring / stator / flagellin”，再用 REST 接口看标题、原子数、链数。
- 7CGO（Tan 2021 Cell）：杆、MS 环、LP 环、钩、输出装置，但**没有 C 环、定子、鞭毛丝**。
- 补：8YJT（C 环 CCW，204 链）、6YKM（MotA5B2 定子）、1UCU（鞭毛蛋白，螺旋参数 4.7 Å / 65.8°）。
- 不同实验坐标系不同 → 做“组件”机制：各自 PCA 定向到同一根轴，按锚点实体（M 环、钩）给高度，定子按环形均布。

## 4. 测试结果
- 预设全部加载成功：鞭毛马达 154,557、ATP 合酶 4,638、钾通道 388、GroEL 8,015、核糖体 10,406、核小体 1,266、蛋白酶体 6,256、HK97 衣壳 115,140 个团块；任意输入 4HHB 574 个。
- 控制台无错误。
- 无显卡电脑（Microsoft Basic Render Driver）：鞭毛马达 低 ≈10 fps、中 ≈18 fps（1280×720）。独显未实测（预期流畅）。

## 5. 经验
- 先用 curl 把每个外部接口跑通（含跨域头），再写前端。
- 画面问题一定要截图看；第 2、3 轮“没有报错”但画面完全不对。
- 发光类效果先全关、调好明暗，再逐项加。
- 组合多个 PDB 时，取景、膜半径等“尺寸”要分清按主结构还是按全部。

## 6. 第二版（v2）：光影重调 + 小分子 + 相互作用动画

### 需求
用户在 RTX 5070 Ti 上看了 v1：科学性有了，但**光影不够美**；希望 ATP 合酶里能看到 **ATP 分子的真实形态和它怎么被合成**（不只是蛋白在转）；后期要能**导入已有结构和最新论文**做动画；所有做法写进 skill。

### 设计
- 光影：参考图是“强顶光 + 无底光 + 彩色轮廓光”，底面沉入黑色。改为顶部主光 + 冷蓝背光 + 品红侧光，删掉底部补光；着色器边缘光乘以“朝上程度”；加调色 pass（饱和、对比、暗角、颗粒），去掉 CSS 暗角。
- 小分子：GraphQL 加查非聚合物实体，ModelServer 按实体号下载配体原子；球棍 InstancedMesh；CCD 理想 SDF 作为动画模板。
- 过程动画注册表 `PROCESSES`；ATP 合酶换成带核苷酸的 6ZPO；两构象变形（Horn 叠合）；本地文件导入。

### 调试轮次（无显卡机器、内置浏览器）
| 轮次 | 看到的问题 | 原因 | 修改 |
|---|---|---|---|
| 1 | 计数器不动、帧率 “—” | 浏览器面板隐藏，rAF 暂停 | 测试前显示面板（写进 troubleshooting） |
| 2 | 整幅画面粉白雾 | bloom 0.65 / 阈值 0.55 太低；半透明 α/β 叠加 | bloom 0.35 / 0.45 / 0.75 |
| 3 | 转子轴歪；M3L 被当成配体 | PCA 轴不是转轴；链内修饰残基是 HETATM | `axisFrom: [c 环, β]`；label_seq_id>0 的 HETATM 当残基 |
| 4 | 半透明外壳成奶白雾，看不到内部 | 多层透明叠加 | 改成“剖开”：先逐片元裁剪 |
| 5 | 剖开的团块像玻璃泡泡 | 裁剪露出空心球 | 改为整颗团块去掉（顶点着色器塌缩） |
| 6 | 近看一片糊 | 景深光圈随距离反比放大 | 近处减弱；默认 0.35 |
| 7 | 催化位点的 ATP 看不见 | 被 AO 压黑 + 被位点前的团块挡住 | 动画物体放进叠加层，在 AO/景深之后渲染 |

| 9 | 分子颜色淡，ATP/ADP 分不清 | 碳原子近白 + 强光 | 碳“故事色”（ATP 金、ADP 青）；球和键加粗；叠加层灯光减弱 |

| 12 | `this.sites` 未定义报错；连点预设场景混合 | setup 未完成就 update；两次加载交错 | setup 完成后才激活；加载令牌 |

### 结果
9 个预设全部加载成功（见 structures.md）；ATP 合酶：H⁺ 在 c 环上转、三个 β 位点循环 ADP+Pi→ATP 并计数；钾通道 K⁺ 单列通过；腺苷酸激酶开合 + Ap5A 在闭合态出现；鞭毛马达 H⁺ 经定子流入。

### 经验
- 埋在蛋白里的小分子，靠“透明”不行，靠“剖开 + 叠加层”。
- 过程动画的状态绑在转子角度上，化学计量自动正确。
- 后期管线里每加一个 pass 都要截图确认，three 的 pass 有隐藏行为（clearDepth）。

## 7. 第三版（v3）：结构示意模式 + 稳定剖面 + 真实构象
用户反馈三点：①蛋白可读性低，要第二种“结构图”模式（保留关键形态，不能过于简略）；②转动时有些结构会消失；③小分子相互作用看不到蛋白构型变化、粗糙；④大结构也要把细节做好，小结构要细致，符合科学性。
1. **消失**：原因是剖面每帧跟随相机，转动时平面附近的团块反复被剖/不剖。改成加载时定一次、固定在模型上的 ±62° 楔形 + 手动“对准”按钮。
2. **结构示意**：只下载了 Cα，所以截面沿 Cα 样条扫掠。二级结构先用 Cα 几何规则，后按用户“符合科学性”的要求改成优先读作者沉积的 `_struct_conf/_struct_sheet_range`（header cif，跨域允许）。6ZPO β 亚基：螺旋 625、折叠 243、卷曲 535 个残基。
   外壳最初想用半透明团块，回避了 v1 的奶白雾问题：深度预写 + LessEqual 只画最外层 + 菲涅尔 alpha。
3. **真实构象**：6ZPO 三条 β 链互相叠合得到替代坐标，C 端结构域摆动最大 14.8–18 Å；配体姿态按 CCD 原子名对齐晶体核苷酸，随口袋插值。测试：20 s 内 ATP 5、H⁺ 11，无报错。
4. **大结构**：HK97（115,140 残基）结构示意约 5.5 M 三角形，鞭毛马达约 7.4 M，加载正常（无显卡机器帧率低，独显应可流畅）。

### v3 追加：简化表示（两次被否定后按调研重做）+ 讲解 + 插画画风
1. 第一版“每条链一个 PCA 椭球”被否定：“过于草率、没有科学性”。
2. 第二版“低分辨率分子表面替代全部”也被否定：用户要求**不是全部替代**，而是由我决定哪些不需要简化，或做成**每部件打勾**，并设默认方式；并要求去查科研里怎么表示亚基。
3. 调研：ChimeraX molmap / Mol* 高斯表面；Goodsell Illustrate 与 Mol* 插画风格（平涂 + 描边 + 遮蔽）；PDB-101 ATP 合酶（转子蓝色系、定子红色系）；Frontiers Microbiol. 2022 ATP 合酶示意图（叶片 / 鼓 / 弯管）。
4. 实现：每部件“简”复选框 + 默认方式（推荐 keepDetail）+ 示意图（环→鼓、长螺旋→弯管、其余→叶片，全部由真实坐标拟合）+ 低分辨率表面 + 插画画风（对所有表示生效）+ 标注讲解。
5. 调试：描边在缩放的叶片上过粗 → 改视空间外推；弯管上有黑色条纹 → 路径平滑 ±6、控制点减到 1/4；白底上团块发白 → 发现 `USE_INSTANCING_COLOR` 在片元着色器不存在的老 bug（边缘光一直是白色），改条件后颜色正确；白色部件在白底上看不见 → 插画画风自动压暗浅色。
6. 之后由两个独立审计智能体（科学性、视觉/前端）审查。

### v3 审计后修正（两个审计智能体：科学性 + 视觉/前端）
- **β 循环方向反了（科学 H1）**：空的 βE 原来按位置猜；改为**构象离群者**（三条 β 链两两 RMSD，与另两条差别最大的是开放的 βE）。6ZPO：βE = label F（auth E），松弛 = E（βDP），紧密 = G（βTP）。
- **KcsA 过滤器位置**：改为取结构里沉积的 K⁺ 离子位置（`this.dir` 定方向），K⁺ 从胞内侧走向过滤器。
- **二级结构**：作者注释只有螺旋没有折叠时（`a.ssK = 1`）不信任“无折叠”，折叠部分仍用几何判定。
- **文字**：δ/ε/OSCP 命名、IF1 抑制态、冷冻电镜（非晶体）表述、ATP/Pi 为按 ADP 位置建模的示意；定子物种说明；鞭毛马达计数器“H⁺（示意）”。
- **示意图**：叶片半轴改为 √5·SD + 1.5 Å，只用球状核心拟合；先判管再做核心过滤（否则外周茎变成巨大叶片）；单个蛋白按结构域分（腺苷酸激酶用预设 `domains` 的文献范围）；核小体用预设 `lobes` 把组蛋白画成 8 个球。
- **前端**：标签避让只做有限位移，放不下就淡出（0.28）；底部说明加底衬（深/浅两种）；面板窄屏适配；`disposeObj` 释放小分子和过程对象；调色/重建后重新应用剖面。

### v4：按功能分区 + 小分子聚焦 + 能量条（2026-11）

### v5：选择集 + 点选 + 能量步骤联动 + 口袋表面（2026-11）
- 用户给了 NGL / iCn3D / PV 等参考，要求“借鉴，不强制照搬”。决定：采用 iCn3D 的选择集驱动交互和 NGL 的高斯表面 + Worker；cartoon 已有、全分子表面与拆多文件不做（architecture §19–20 末尾写了理由）。
- 实现：统一选择集、射线对残基球拾取（15 万残基 ~30 ms）、淡化 + 金色透视标记、缓动镜头、信息卡（作者编号、化学性质、层、离小分子距离）、能量条 `energyHL` 与“◎ 跟随”、聚焦时 Worker 算口袋表面。
- 调试：选中后别的部件不淡化、自己反而被隐藏 → `userData.outline` 主网格上是引用，改 `=== true`（同时修好 v4 聚焦里隐藏主形状的 bug）；金色标记加法混合在辉光下变白 → 普通混合；AdK 聚焦出现 2.0 Å“盐桥” → 1AKE 的 Ap5A 交替构象，< 2.4 Å 的 N/O 对不计入并注明；KcsA 过滤器 TVGYG 用作者编号 75–79（label 是 53–57）。

### v6：价键模型 + 线粒体呼吸链（2026-11）
- 用户：局部细节里小分子除球棍外要有价键模型；不做病毒衣壳（删除 HK97 预设）；方向转向“蛋白质机理 + 多机器协同（含能量转化）”：线粒体、叶绿体、噬菌体侵染、各种酶。
- 本轮完成：价键 / 空间填充画法（CCD 键级）；场景参数（axisFit、groupParts、组件 axisFrom/alignTo/beside/split/pivot、frameAll、broadside 镜头）；线粒体呼吸链预设与过程。
- 调试：'复合体 I' 作为颜色键匹配了 '复合体 III/IV'（全部变蓝）→ 正则键；组件无 anchor 时被对齐到第一个实体（ATP 合酶 c 环比膜低 67 Å）→ 修 placeComponent；镜头只框主结构 → frameAll；斜视时 ATP 合酶挡住复合体 IV → broadside。
- 待做：叶绿体光反应链（PSII → PQ → b6f → PC → PSI → Fd → FNR + ATP 合酶）、噬菌体侵染（尾鞘收缩、DNA 注入，两态）、酶机理（诱导契合、催化三联体等）。

### v7：叶绿体光反应（2026-11）
- 7 个植物结构拼成类囊体膜上的一排：PSII-LHCII → b6f → PSI-LHCI → ATP 合酶，质体蓝素在腔里、铁氧还蛋白和 FNR 在基质侧穿梭；Z 方案电子流沿真实辅因子位置。
- 调试：3JCU 的锰簇 / 去镁叶绿素 / 叶绿素没下载（每个结构只取前 12 种小分子）→ 24 种 + 按 coreLigands 排序；膜是围绕主结构的圆盘，够不到 PSI / ATP 合酶且挡住 PSII → frameAll 场景改成沿排方向的条带 + 朝向镜头的剖切面。
- 用户下一步想法：画面“质感”不够；希望展现细胞内部动态过程（区域变化、浓度等）、多蛋白协同的生命过程。

### v8：插画画风的质感（2026-11）
- 用户：白底描边方向可以，但不够清晰、没质感，重点做这个方向。
- 实现：屏幕空间墨线（深度轮廓 + 沟槽细线）、宏观明暗（深度梯度法线）、远处淡出、膜脂浅线标记、去掉反转外壳、插画模式不做色调映射。
- 调试：逐残基边缘变暗 → 一团“肥皂泡”，改为几乎平涂 + 屏幕空间宏观明暗；去掉 ACES 后调色 pass 的饱和度 1.3 把颜色推成荧光 → 插画模式饱和度 1.0；外壳描边被淡出染灰成光晕 → 插画模式不用外壳；透过半透明 LHCII 的膜脂丢了标记（混合覆盖 alpha）→ 半透明材质不写 alpha；质体蓝素被判为支架变半透明 → `solid`。
