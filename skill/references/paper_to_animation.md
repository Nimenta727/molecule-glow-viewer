# 从“已有结构 + 最新论文”做成动画

用户会给：一篇论文（PDF / DOI / 标题）、一个机制描述、或自己的结构文件。目标：在查看器里做出**能看到相互作用**的动画预设。

## 流程

### 1. 从论文提取“动画剧本”（先写下来给用户确认）
读论文的摘要、结构图图注、机制示意图、方法里的“Data availability”，填这张表：

| 项 | 例子（ATP 合酶） |
|---|---|
| 主角复合物 | 牛线粒体 ATP 合酶单体 |
| 结构编号（PDB / EMDB） | 6ZPO（状态 1），6ZQM、6ZQN（状态 2、3） |
| 结构里有什么小分子 | ATP、ADP、Mg、心磷脂 |
| 运动部件 / 静止部件 | 转子 γδε + c8 环 / α3β3、外周柄、a 亚基 |
| 有几个构象状态，各代表什么 | 3 个旋转状态（γ 相差约 120°） |
| 驱动力与方向 | H⁺ 从膜间隙经 a 亚基流入基质 |
| 化学计量 | 每转 8 H⁺、3 ATP |
| 关键事件的顺序 | 开放 → 松弛 → 紧密（ADP+Pi→ATP）→ 开放释放 |
| 关键残基 | c 亚基 Glu58、a 亚基 Arg159（示例：以论文为准） |
| 哪些是推测 / 示意 | 质子路径的精确几何 |

不确定的写“待确认”，不要编。论文没给 PDB 编号时，用标题/作者在 RCSB 搜索（structures.md 命令），并核对发表年份和作者。

### 2. 确认结构（命令见 structures.md）
- 标题、分辨率、实体名称（预设关键词从这里挑）、非聚合物实体（小分子代码）。
- 多状态：确认几个条目的**链名一致**（`states` 按 `链|残基号` 配对）。不一致时只能分别做预设。
- 只有 EMDB 密度图、没有模型：本查看器不显示密度图；告诉用户，并找同一复合物最近的 PDB 模型。
- 论文结构还没公开 / 用户有自己的模型：用“导入本地文件”（.cif/.pdb）。本地文件的部件名来自 `_entity.pdbx_description`（mmCIF）或链名（PDB 格式）。

### 3. 写预设
- 旋转机器：`axisFrom` + `spin`；遮住位点的外壳：`ghost`；膜蛋白：`membranes`；
- 两个状态的开合：`states: [A, B]`（+ `chains` 只留一个拷贝，`colorMode: 'rainbow'` 看结构域）；
- 配色：功能相同的部件同色，驱动部件（转子）用白/浅色，小分子用故事色。
- 先不加过程，加载、截图，确认方向和构图对。

### 4. 写过程动画
按 processes.md 的模板：位点来自结构里的配体；状态跟转子角度或时间绑定；化学计量和论文一致；计数器显示关键产物。
说明文字写成“谁（颜色）→ 做什么 → 结果”，一行能读完。

### 5. 验证与交付
- SKILL.md 步骤 6 的检查清单全部通过，截图（全景 + 位点特写）。
- 回复用户：用了哪些结构（编号 + 论文）、动画表达了什么、**哪些是示意**（如拼接位置、离子路径、放大的小分子）。

## 本地文件说明（导入）
- mmCIF：读 `_atom_site`（任意列顺序）和 `_entity`；PDB：固定列。
- 残基 = CA（蛋白）/ P（核酸）；HETATM 非水 → 配体，自动成键并显示。
- 本地文件不展开组装体（文件里有几条链就显示几条）。
- 想对本地文件加预设：`loadScene({ local: __viewer.entryFromFile(名字, 文本), axis: 'long', ... })`，或者把文件放到 http 服务器目录里，在代码中 fetch 后调用 `entryFromFile`。

## 例子：一句话需求 → 预设
“我想看 SERCA 钙泵怎么把 Ca²⁺ 泵进内质网”
1. 剧本：E1·2Ca²⁺（1SU4）→ E2（1IWO）；两个 Ca²⁺ 结合位点在跨膜区；ATP 结合在 N 结构域，磷酸化 P 结构域 Asp351。
2. 确认两条目的链名、Ca 的实体（先查！编号以查询结果为准）。
3. 预设：`states: ['1SU4','1IWO']`、`membranes`、`colorMode: 'rainbow'`。
4. 过程：Ca²⁺ 粒子在 morph<0.4 时停在位点，morph>0.6 时沿 +y 离开；ATP 分子在 N 结构域附近出现、磷酸转移闪光。
