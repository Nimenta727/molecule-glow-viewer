# 光影：怎么调出参考图那种效果

参考图（B 站鞭毛马达动画截图）的光影要点，以及在查看器里对应的实现与数值：

| 参考图特征 | 实现 | 数值 |
|---|---|---|
| 纯黑背景、四角压暗 | 黑背景 + 调色 pass 暗角 | 暗角 0.45 |
| **强顶光**：上表面亮、下表面沉入黑 | 白色主光从上方；半球光地面色为黑；**没有底部补光** | 主光 3.2 @(0.35,1,0.45)，半球 0.12 |
| 轮廓带彩色光边 | 冷蓝背轮廓光 + 品红侧补光 + 着色器菲涅尔边缘光（只在朝上的面强） | 2.4 / 1.2；边缘光 0.55 |
| 团块像带釉的软糖，有小高光 | MeshPhysical：clearcoat 1.0，粗糙度 0.12–0.3；sheen 很少 | sheen 0.08（多了发白） |
| 团块之间缝隙暗 | GTAO | 中/高画质开 |
| 颜色浓、不发灰 | 低环境光 + 调色饱和度、对比度 | 环境 0.12，饱和 1.3，对比 1.12，曝光 0.88 |
| 柔和泛光但颗粒仍清楚 | Bloom 阈值高、强度低 | 0.35 / 半径 0.45 / 阈值 0.75 |
| 远近有虚实 | 景深对焦旋转中心，近看自动减弱 | 0.35 |
| 配色：粉 / 浅蓝 / 绿 / 深蓝 / 白 / 橙 | 预设 `colors` | 粉 #e64fc8，浅蓝 #5b9dff，绿 #3fc864，深蓝 #2448e8，白 #e3e7f2，橙 #ff9a50 |
| 剖开看内部 | 部件“剖”/ 膜剖切 | 珠子式剖面（整颗团块去掉） |
| 小分子醒目 | 叠加层绘制 + 自发光 + 碳原子着“故事色” | ATP 碳 #ffb300，ADP 碳 #00c8ff |

## 调参顺序（一次只动一项）
1. 构图：画质“中”，确认方向、主体占 50–80%。
2. 团块大小：同一条链的团块刚好挤在一起（4.4–5.0）。
3. 颜色：功能部件给固定色，相邻部件对比色；白色部件不要用纯白（#e3e7f2），否则一进 bloom 就成白雾。
4. 明暗：先辉光 0，调曝光让最亮处不过曝；开 AO。
5. 发光：边缘光到轮廓明显；辉光加到“有光晕但颗粒清楚”。
6. 小分子：拉近到催化位点截图，确认颜色可辨、不发黑。
7. 景深、运动最后加。

## 常见失败画面（都实际出现过）
| 画面 | 原因 | 调整 |
|---|---|---|
| 一大片白光 / 粉雾 | 辉光、自发光、曝光太高；白色部件进 bloom | 辉光 ≤0.4、阈值 ≥0.75；白色降到 #e3e7f2 |
| 奶白雾挡住内部 | 外壳用了半透明 | 改用“剖” |
| 团块像玻璃泡泡 | 逐片元裁剪露出空心 | 用整颗团块剖开（已内置） |
| 近看一片糊 | 景深光圈随距离变大 | 已改为近处减弱；或关景深 |
| 配体发黑 / 看不见 | 被 AO 压暗、被团块挡住 | 放进叠加层（过程动画物体自动如此） |
| 颜色发灰 | 环境光太强、sheen 太高 | 降环境光；sheen ≤0.1；饱和度 1.3 |
| 看起来像一堆原子点 | 团块太小 | ≥4.4 |
